# Proxy Recovery Evaluator
Use this skill to judge soft-mode proxy recovery. It requires explicit proxy declaration, numeric CFM loss decrease, optimizer parameter changes, OT path/target checks, ODE check, and generated-skill invocation evidence. Run `python tests/test_proxy_eval.py`.

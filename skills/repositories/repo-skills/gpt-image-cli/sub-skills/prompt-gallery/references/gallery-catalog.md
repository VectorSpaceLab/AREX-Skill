# Gallery Catalog

This catalog is a distilled operating map of the prompt gallery. Use it to choose the smallest useful prompt family before writing. Do not treat it as a prompt dump; the value is the recurring structure behind each category.

## Loading policy

- Pick **one primary category** for ordinary requests.
- Pick **two or three categories** only for explicit hybrids, such as a product hero plus brand-system board, an academic method figure plus data visualization, or an anime game HUD plus character sheet.
- When categories compete, select by output artifact first: paper figure, poster, UI screen, product campaign, game screenshot, edit, etc. Use style categories second.
- Preserve gallery metadata when turning examples into public entries: `Curated` for repo-created/reworked material; `Author + Source` for outside-source/community material.

## Category selection signals

Use these signals to break ties:

- **Research/data/technical**: if correctness depends on labels, arrows, axes, legends, panel letters, or chart semantics, prefer `Research Paper Figures`, `Data Visualization`, or `Technical Illustration` over generic illustration.
- **Text-heavy commercial output**: if the result has titles, prices, dates, slogans, CTA, or Chinese copy, prefer `Typography & Posters`, `Infographics & Field Guides`, or `Events & Experience`; require exact copy in quotes.
- **App or dashboard**: if the output is a product interface, choose `UI/UX Mockups`; add `Data Visualization` only for chart-heavy dashboards.
- **Style vs artifact**: if the user asks for "anime research figure," the artifact is still a research figure; use `Research Paper Figures` primary and `Anime & Manga` as a bounded style influence.
- **Edit request**: if any source image must stay recognizable, use `Edit Endpoint Showcase` for invariant language, then route execution to the CLI/API sub-skill.
- **Community pattern provenance**: gaming, research figures, posters, infographics, product posters, isometric, pixel art, character sheets, and cinematic scenes include outside-community patterns in the source gallery. If adapting those patterns for a public entry, keep `Author + Source` metadata.

## Hybrid examples

- **Chinese-label ablation figure** -> `Research Paper Figures` + `Data Visualization` + optional `Typography & Posters` for exact Chinese copy discipline.
- **Premium beverage identity board** -> `Product & Food` + `Brand Systems & Identity` + optional `Typography & Posters` for campaign hierarchy.
- **Mobile banking app hero screen with charts** -> `UI/UX Mockups` + `Data Visualization` + optional `Brand Systems & Identity` for product-system consistency.
- **Anime open-world game screenshot** -> `Gaming` + `Anime & Manga`; add `Cinematic & Animation` only if storyboarding/camera beats matter.
- **Museum-style anatomy teaching poster** -> `Scientific & Educational` + `Infographics & Field Guides`; add `Technical Illustration` for cutaway/exploded anatomy logic.
- **Reference photo turned into winter poster** -> `Edit Endpoint Showcase` + `Typography & Posters` if text/layout must be preserved or replaced.

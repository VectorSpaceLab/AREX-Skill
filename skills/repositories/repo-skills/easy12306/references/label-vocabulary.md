# Label Vocabulary

## Purpose

Use this reference whenever an easy12306 model output class id must be converted to a Chinese label. Both the text prompt model and the image-tile model use this exact 80-row order.

## Contract

- Encoding: UTF-8, one label per row.
- Expected rows: 80.
- Class id: zero-based row index.
- Do not sort, translate, de-duplicate, or insert headers into a runtime `texts.txt` file; doing so changes model semantics.

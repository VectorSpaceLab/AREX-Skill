# Data preparation troubleshooting

Use [`../scripts/validate_layout.py`](../scripts/validate_layout.py) first. It catches most folder and extension errors without importing the repository or launching training.

| Symptom | Likely cause | Recovery |
| --- | --- | --- |
| `is not a valid directory`, missing `trainA`, missing `trainB`, missing `train`, or missing `test` | `--dataroot` points to the wrong level, or the selected `--dataset_mode` does not match the folder layout. | Match mode to layout: `unaligned` expects `<phase>A/<phase>B`; `aligned` and `colorization` expect `<phase>/`; `single` expects `--dataroot` to point directly at an image folder. Re-run the validator with `--phase train` or `--phase test` to isolate a split. |
| Runtime reports zero images or validator reports zero supported images | Directory exists but contains no recognized image extensions, contains only metadata, or images are nested somewhere other than the selected split. | Use the supported extensions from [`data-layouts.md`](data-layouts.md). Move or convert unsupported formats before training. The repository-style loader searches recursively, so if recursive validation finds zero files the selected root is almost certainly wrong. |
| Unaligned CycleGAN data fails for a missing test side | Only `testA` or only `testB` exists while the full CycleGAN test mode expects both domains. | Either provide both `testA` and `testB`, test on `--phase train` if intentionally using training images, or use one-sided `--model test` with `single` loading when only one domain is needed. |
| pix2pix aligned data loads but outputs are reversed | Side-by-side AB orientation does not match `--direction`. | Aligned images are split left=A, right=B. Use `--direction AtoB` for left-to-right and `--direction BtoA` for right-to-left. Cityscapes conversion in this skill writes photos left and color label maps right, so labels-to-photos uses `BtoA`. |
| Pair combining fails with missing filenames | A and B folders do not contain identical relative filenames, or the source uses `_A`/`_B` suffixes but suffix matching was not enabled. | Rename files so corresponding A/B images share the same name, or run [`../scripts/combine_pairs.py`](../scripts/combine_pairs.py) with `--use-ab-suffix` when files follow `name_A.ext` and `name_B.ext`. Inspect the combiner's missing/extra filename examples before changing data. |
| Pair combining fails with size mismatch | A and B images for the same filename have different width or height. | Resize or crop the raw A/B images with an explicit preprocessing step before combining. The bundled combiner refuses silent resizing so that paired supervision remains auditable. |
| Existing output files block pair combining or Cityscapes conversion | Safe scripts do not overwrite generated images by default. | Review the destination. If the existing files are intentionally replaceable, rerun with `--overwrite`; otherwise write to a new output directory. |
| `load_size` / `crop_size` assertion or crop error | `load_size < crop_size`, images are too small for `--preprocess crop`, or a train/test command uses inconsistent resize/crop settings. | Keep `load_size >= crop_size`. For high-resolution or rectangular data, choose preprocessing deliberately and keep train/test scales compatible. If no resize is requested, ensure dimensions satisfy the generator divisibility rule below. |
| Output/input shape mismatch with `--preprocess none` | Generator downsampling requires dimensions divisible by the architecture's scale. | Use dimensions divisible by 4 for ResNet generators, divisible by 128 for `unet_128`, and divisible by 256 for `unet_256`, or use resize/crop preprocessing. |
| Colorization data was incorrectly combined into AB files | Colorization expects natural RGB images and converts them to Lab L/ab channels internally. | Restore a normal `train/` and `test/` folder of RGB images. Use `--model colorization --dataset_mode colorization`; do not run A/B pair combination. |
| Cityscapes converter finds zero pairs | The argument points to the wrong extraction level, or the expected files are absent. | Pass the extracted `gtFine` directory to `--gtFine-dir` and the extracted `leftImg8bit` directory to `--leftImg8bit-dir`; each phase should contain nested city folders with files matching `*_gtFine_color.png` and `*_leftImg8bit.png`. |
| Cityscapes converter reports mismatched identifiers | Color label maps and photos do not share the same Cityscapes identifier. | Ensure every `CITY_SHOT_FRAME_gtFine_color.png` has a corresponding `CITY_SHOT_FRAME_leftImg8bit.png` for the same phase. Do not mix phases or cities from different downloads. |
| Dataset download helper rejects the name | Dataset names are strict and differ between CycleGAN zip assets and pix2pix tar assets. | Consult [`asset-downloads.md`](asset-downloads.md). Do not invent a URL for an unsupported name. |
| Download fails, stalls, or leaves partial data | Network unavailable, `wget`/archive tools missing, archive is large, or storage is insufficient. | Ask for explicit network approval, verify free space, clean partial archives deliberately, and retry only the selected asset. Prefer synthetic/local fixtures for verification. |
| Cityscapes download is unavailable from the helper | Cityscapes is excluded for license reasons. | The user must obtain `gtFine` and `leftImg8bit` through the Cityscapes licensing process, extract them, then run the bundled converter locally. |
| Historical/source `combine_A_and_B.py` fails before combining | The old implementation depends on OpenCV and referenced `Path` without importing it in the inspected version. | Use the bundled Pillow adapter [`../scripts/combine_pairs.py`](../scripts/combine_pairs.py), which has parser help, strict matching diagnostics, no OpenCV dependency, and no repository imports. |

## Quick diagnosis flow

1. Run the validator for the intended mode and phase.
2. If the task is paired pix2pix and raw A/B folders are separate, run the combiner in `--dry-run` first.
3. If the task is Cityscapes, run the converter on one tiny or limited subset with `--limit 1 --dry-run` or a scratch output directory, then validate both `aligned` and `unaligned` layouts.
4. Route to model command construction only after the final `--dataroot` validates for the intended mode.

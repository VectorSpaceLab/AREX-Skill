# License and Citation Notes

Use this reference when the user asks whether they may use Baichuan2 commercially, redistribute derivatives, or cite the model family.

## License posture from the repository

The repository states that Baichuan2 model use requires both:

- Apache 2.0 for repository materials, and
- the Baichuan2 Model Community License for model usage.

The README says the model supports commercial use after users satisfy the community-license conditions and obtain permission when required. It highlights conditions including daily active user limits, restrictions for software/cloud service providers, and no sublicensing without Baichuan permission.

When a user asks for legal certainty, do not treat this skill as legal advice. Tell them to review the current model license text from the model card or official release and obtain counsel or permission when required.

## Safety and compliance reminder

The repository explicitly warns users not to use Baichuan2 for unlawful or socially harmful activity, and asks users to follow applicable safety review and filing requirements for internet services.

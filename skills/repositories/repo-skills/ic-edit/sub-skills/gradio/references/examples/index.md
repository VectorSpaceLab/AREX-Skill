# Bundled example presets

These presets are loaded by `scripts/run_icedit_gradio.py` through the Gradio `Examples` widget.

| Image | Prompt | Seed | Notes |
| --- | --- | ---: | --- |
| `girl.png` | `Make her hair dark green and her clothes checked.` | `304897401` | Photo-editing baseline from the source demo. |
| `boy.png` | `Change the sunglasses to a Christmas hat.` | `748891420` | Attribute change and object swap example. |
| `kaori.jpg` | `Make it a sketch.` | `484817364` | Style-transfer example. |

If you replace these assets, keep the filenames in sync with the helper or update both together.

# PaperQA Cross-Cutting Troubleshooting

Use this page for failures that span multiple PaperQA workflows. For workflow-specific details, switch to the relevant sub-skill troubleshooting page.

## Install or import failures

| Symptom | Likely cause | Recovery |
| --- | --- | --- |
| `ModuleNotFoundError: paperqa` | Package is not installed in the active Python environment. | Install `paper-qa` into the Python that will run the task; verify with `python -c "import paperqa"`. |
| PDF import error says no parser function is available | Neither the default `paper-qa-pypdf` dependency nor another parser extra is importable. | Install `paper-qa[pypdf]` or choose a reader extra and configure `Settings(parsing={"parse_pdf": ...})`. |
| `QdrantVectorStore` raises `ImportError` | `qdrant-client` extra is missing. | Install `paper-qa[qdrant]` and configure or provide an async Qdrant client. |
| Office files cannot parse | `unstructured` Office dependencies are missing. | Install `paper-qa[office]`; for PDF/text-only work, route away from Office parsing. |
| Local sentence-transformer embeddings fail to import | `sentence-transformers` extra is missing or model download/cache is unavailable. | Install `paper-qa[local]`; confirm model cache/network policy before using `st-*` embeddings. |

Run the bundled readiness helper without network or LLM calls:

```bash
python scripts/check_paperqa_env.py --json
```

## Provider credentials and model roles

PaperQA has multiple model roles. Changing only one can leave another defaulting to OpenAI:

- `Settings.llm`: citation inference, answer generation, fake-agent search proposals, prompt hooks.
- `Settings.summary_llm`: contextual summaries during evidence gathering.
- `Settings.agent.agent_llm`: tool selection for the agent.
- `Settings.embedding`: embedding provider for indexing/retrieval.
- `Settings.parsing.enrichment_llm`: multimodal media enrichment when enabled.

If a run still asks for an OpenAI key after switching to Anthropic/Gemini/local models, inspect all roles and any named config overrides. See [settings-and-configuration](../sub-skills/settings-and-configuration/SKILL.md).

## Network, rate limits, and cost

`pqa ask`, `Docs.aquery`, `ask`, `agent_query`, metadata hydration, OpenReview, Zotero, and ClinicalTrials.gov workflows may call external services. Before running them:

1. Identify the active model and metadata providers.
2. Confirm required API keys are set, without printing secret values.
3. Use named tier-limit settings or LiteLLM router rate limits when needed.
4. Use `Settings.from_name("fast")` or smaller `answer.evidence_k`/`answer.answer_max_sources` for lower cost.
5. Prefer no-network smoke scripts when the task is only environment validation.

## Index and state location confusion

PaperQA stores settings, indexes, and answer history under `PQA_HOME` (defaulting to a user home location) and appends `.pqa` below it. A task that reuses a prebuilt index must align:

- `agent.index.index_directory`
- `agent.index.name` or the autogenerated `Settings.get_index_name()`
- `agent.index.paper_directory`
- parser/embedding/chunking settings used to build the index

Use [cli-and-indexing](../sub-skills/cli-and-indexing/SKILL.md) for manifest and index lifecycle details.

## Parsing and data validation failures

- Empty, corrupt, encrypted, or image-only PDFs can produce `ImpossibleParsingError` or empty contexts.
- Media parsing can require `pypdfium2`, Pillow, pdfplumber, PyMuPDF, Docling, or a Nemotron API/SageMaker endpoint depending on reader choice.
- Code/Markdown/HTML/Office files have different parser paths and chunking behavior.
- Manifest CSVs should keep `file_location` relative to the paper directory when indexes need to be shareable.

Use [docs-and-parsing](../sub-skills/docs-and-parsing/SKILL.md) for parser selection and [cli-and-indexing](../sub-skills/cli-and-indexing/SKILL.md) for manifest validation.

## Metadata and source acquisition failures

- Crossref, Semantic Scholar, OpenAlex, Unpaywall, and retraction checks can return no result, rate-limit, or disagree on fields.
- ClinicalTrials.gov can reject malformed queries with HTTP 400-like messages.
- Zotero and OpenReview helpers require extras, credentials, and user-authorized downloads.
- Third-party scraping may violate provider terms or rights; prefer authorized APIs and user-supplied PDFs.

Use [metadata-and-sources](../sub-skills/metadata-and-sources/SKILL.md) for provider composition and safe no-network inspection helpers.

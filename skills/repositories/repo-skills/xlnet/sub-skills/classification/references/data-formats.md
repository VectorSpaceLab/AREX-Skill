# Data formats for `run_classifier.py`

`run_classifier.py` does not have flags for arbitrary filenames, column numbers, or label sets. Each `task_name` selects a processor class with hard-coded filenames, columns, labels, and split behavior.

## Processor map

| `task_name` | Processor | Train source | Eval/dev source | Test/predict source | Labels / target | Notes |
| --- | --- | --- | --- | --- | --- | --- |
| `mnli_matched` | `MnliMatchedProcessor` | `train.tsv` | `dev_matched.tsv` | `test_matched.tsv` | `contradiction`, `entailment`, `neutral` | GLUE TSV with header; sentence pair classification. |
| `mnli_mismatched` | `MnliMismatchedProcessor` | `train.tsv` | `dev_mismatched.tsv` | `test_mismatched.tsv` | `contradiction`, `entailment`, `neutral` | Same training file as matched, different dev/test files. |
| `sts-b` | `StsbProcessor` | `train.tsv` | `dev.tsv` | `test.tsv` | Float score | Regression; must use `--is_regression=True`. |
| `imdb` | `ImdbProcessor` | `train/neg/*.txt`, `train/pos/*.txt` | `test/neg/*.txt`, `test/pos/*.txt` | No separate unlabeled test reader | `neg`, `pos` | `eval_split=dev` reads the labeled IMDB `test` folders. |
| `yelp5` | `Yelp5Processor` | `train.csv` | `test.csv` | No separate unlabeled test reader | `1`, `2`, `3`, `4`, `5` | CSV rows are consumed as data; do not include a header row unless it is intended as an example. |

## GLUE TSV processors

The GLUE-style processors read TSV files with headers and skip the first row for train/dev/test.

### MNLI

Expected files inside `data_dir`:

```text
data_dir/
  train.tsv
  dev_matched.tsv
  dev_mismatched.tsv
  test_matched.tsv
  test_mismatched.tsv
```

Column use is 0-indexed in the source processor:

| Split | Text A column | Text B column | Label column |
| --- | ---: | ---: | --- |
| Train/dev | 8 | 9 | last column (`-1`) |
| Test | 8 | 9 | dummy label generated by processor |

The processor silently skips incomplete lines where the required text or label column is missing. If too many examples are skipped, inspect TSV column count and quoting.

### STS-B

Expected files inside `data_dir`:

```text
data_dir/
  train.tsv
  dev.tsv
  test.tsv
```

Column use is 0-indexed:

| Split | Text A column | Text B column | Label column |
| --- | ---: | ---: | ---: |
| Train/dev | 7 | 8 | 9 |
| Test | 7 | 8 | dummy `0.0` |

STS-B labels are parsed with `float(...)`; non-numeric score cells will fail. Because the model head and TFRecord schema differ for regression, every STS-B command must include `--is_regression=True`. Reusing a classification TFRecord cache for STS-B is invalid.

## IMDB directory layout

Expected files inside `data_dir`:

```text
data_dir/
  train/
    neg/*.txt
    pos/*.txt
  test/
    neg/*.txt
    pos/*.txt
```

Behavior:

- Labels are directory names: `neg` and `pos`.
- Only filenames ending in `txt` are consumed.
- HTML line breaks `<br />` are replaced with spaces.
- `get_dev_examples(data_dir)` reads the labeled `test` folders.
- There is no separate `get_test_examples`; use `eval_split=dev` for eval/predict on the labeled test folders.

For a binary single-document custom task, converting examples into this folder layout is often easier than editing code. Keep class names exactly `neg` and `pos` unless you add a new processor.

## Yelp-5 CSV layout

Expected files inside `data_dir`:

```text
data_dir/
  train.csv
  test.csv
```

Each row is parsed as standard CSV:

| Column | Meaning |
| ---: | --- |
| 0 | Label string, exactly one of `1`, `2`, `3`, `4`, `5`. |
| 1 | Review text. The processor normalizes doubled/escaped quotes. |

There is no header skip. A header row such as `label,text` will be treated as a malformed training example and will fail label mapping. The processor uses `test.csv` for evaluation/dev.

## Generated feature schema

All processors become `InputExample(guid, text_a, text_b, label)`, then `classifier_utils.convert_single_example` writes fixed-length features:

| Feature | Type in TFRecord | Shape | Meaning |
| --- | --- | --- | --- |
| `input_ids` | int64 | `[max_seq_length]` | SentencePiece token ids plus separator/classification ids. |
| `input_mask` | float32 | `[max_seq_length]` | `0` for real tokens and `1` for padding. |
| `segment_ids` | int64 | `[max_seq_length]` | Segment A/B/CLS/SEP/PAD ids. |
| `label_ids` | int64 or float32 | scalar | Integer label id for classification; float score for regression. |
| `is_real_example` | int64 | scalar | `0` only for eval padding examples. |

Sequence construction details:

- Single text: `tokens_a + SEP + CLS`, then left-padded to `max_seq_length`.
- Text pair: `tokens_a + SEP + tokens_b + SEP + CLS`, then left-padded.
- Pair truncation repeatedly removes one token from the longer side until room remains for two `SEP` tokens and one `CLS` token.
- Single-sequence truncation leaves room for one `SEP` and one `CLS`.

## Custom TSV and similar processor-backed tasks

The built-in CLI cannot select arbitrary TSV columns. For a custom task, choose the least invasive option:

1. **Reshape data to a built-in layout.**
   - Pair regression with numeric labels: arrange as STS-B (`train.tsv`/`dev.tsv`, text columns 7/8, score column 9) and use `task_name=sts-b --is_regression=True`.
   - Three-way sentence-pair classification with MNLI labels: arrange as MNLI columns 8/9 and labels `contradiction`, `entailment`, `neutral`.
   - Binary single-document sentiment: convert to IMDB `train/{neg,pos}` and `test/{neg,pos}` directories.
   - Five-class single-document review ratings: convert to Yelp-5 CSV with labels `1` through `5`.
2. **Add a new processor in the caller's working copy.** Define a `DataProcessor` subclass with the desired files, columns, and labels, then add it to the processor map before invoking the generated command shape.
3. **Use lower-level model APIs** if the task needs a different head, multi-label outputs, extra features, or nonstandard metrics; route to `../../model-api/`.

When reshaping custom TSV data, keep train/dev/test schemas aligned. A command that works for train can still fail in eval/predict if the dev/test files do not contain the columns expected by the same processor.

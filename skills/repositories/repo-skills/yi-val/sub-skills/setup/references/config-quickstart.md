# Config quickstart

YiVal configs are YAML mappings loaded by OmegaConf and treated like dictionaries at runtime. Keep field names exact.

## Minimal CSV + expected-result evaluator

```yaml
description: Offline question-answer evaluation
custom_function: my_task.answer_question
dataset:
  source_type: dataset
  file_path: /absolute/path/to/data.csv
  reader: csv_reader
  reader_config:
    expected_result_column: expected_result
    chunk_size: 100
variations:
  - name: answer_style
    variations:
      - value_type: str
        value: ""
        instantiated_value: ""
        variation_id: null
      - value_type: str
        value: "Think first, then answer with only the option."
        instantiated_value: "Think first, then answer with only the option."
        variation_id: null
evaluators:
  - evaluator_type: individual
    matching_technique: includes
    metric_calculators:
      - method: AVERAGE
    name: string_expected_result
```

Custom function shape:

```python
from yival.schemas.experiment_config import MultimodalOutput
from yival.states.experiment_state import ExperimentState
from yival.wrappers.string_wrapper import StringWrapper


def answer_question(question: str, state: ExperimentState) -> MultimodalOutput:
    suffix = str(StringWrapper("", name="answer_style", state=state))
    return MultimodalOutput(text_output=f"4 {suffix}")
```

The CSV must have a `question` column and an `expected_result` column.

## Machine-generated examples

```yaml
description: Generate prompt-test cases
custom_function: my_task.headline
dataset:
  source_type: machine_generated
  data_generators:
    openai_prompt_data_generator:
      chunk_size: 1000
      number_of_examples: 2
      model_name: gpt-4
      output_path: generated_examples.pkl
      diversify: false
      input_function:
        name: headline_generation
        description: Generate a landing page headline for a tech startup business.
        parameters:
          tech_startup_business: str
      prompt: |-
        Provide a concrete realistic test case as a dictionary for ** invocation.
        Only include parameters.
variations:
  - name: task
    generator_name: openai_prompt_based_variation_generator
    generator_config:
      number_of_variations: 2
      model_name: gpt-4
      variables:
        - tech_startup_business
      prompt:
        - role: system
          content: Create concise prompts for GPT-4.
    variations:
      - value_type: str
        value: Generate a landing page headline for {tech_startup_business}
        instantiated_value: Generate a landing page headline for {tech_startup_business}
        variation_id: null
```

Provider-backed generation requires credentials and network access; cache with `output_path` when possible.

## User-input interactive mode

```yaml
description: Interactive translation demo
custom_function: my_task.translate
dataset:
  source_type: user_input
evaluators: []
variations:
  - name: translate
    variations:
      - value_type: str
        value: "Translate the following to Chinese:"
        instantiated_value: "Translate the following to Chinese:"
        variation_id: null
      - value_type: str
        value: "Translate the following to Spanish:"
        instantiated_value: "Translate the following to Spanish:"
        variation_id: null
```

`ExperimentRunner` will open the Dash interactive path rather than preloading dataset rows.

## Multi-config files

`load_and_validate_configs()` accepts either one config mapping or a YAML list of configs. `ExperimentRunner.run()` loops over configs and offsets Dash ports/output pickle names by config index.

## Field pitfalls

- `data_genertaor_names` is misspelled in the CLI option, but YAML uses `data_generators`.
- `variations[].instantiated_value` is generated by `WrapperVariation.__post_init__` when constructed in Python. In YAML examples it is often included; keep it aligned with `value` for static configs.
- Built-in BERTScore default config has typo text `bertsocre_evaluator`, but the registry id is `bertscore_evaluator`.
- Use `model_name` for OpenAI prompt data/variation generators in code-backed configs; some older docs say `openai_model_name` in examples.

# Evaluation troubleshooting

| Symptom | Likely cause | Recovery |
| --- | --- | --- |
| `KeyError` for metric columns | A requested column is missing from one CSV/DataFrame. | Compare `real.columns` and `synthetic.columns`; run column-order processor checks if generated by SDGX. |
| Continuous JSD is slow or memory-heavy | KDE grid grows with number of continuous columns. | Use one or two continuous columns at a time or sample down before exploratory checks. |
| `MISim` metadata key error | Metric metadata dict lacks the source column name or uses SDGX type names directly. | Map SDGX types to `numerical`, `category`, or `datetime`. |
| Metric is valid but output is unusable | Metrics do not enforce schema, row count, PII rules, or domain constraints. | Add structural assertions and data-preparation validations. |
| Benchmark scripts take too long | Source benchmark defaults are million-row/performance oriented. | Use tiny fixtures or the bundled smoke/metric scripts unless the user asked for benchmarks. |

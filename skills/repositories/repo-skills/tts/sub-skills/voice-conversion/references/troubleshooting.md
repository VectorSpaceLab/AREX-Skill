# Voice Conversion Troubleshooting

For package-wide install/import/Python/PyTorch/cache issues, also read [../../../references/troubleshooting.md](../../../references/troubleshooting.md). This file covers FreeVC and TTS+VC workflow failures.

| Symptom | Likely cause | Action |
| --- | --- | --- |
| Output keeps the wrong speaker identity. | `source_wav` and `target_wav` were swapped. | Re-label the files: `source_wav` is the utterance to transform; `target_wav` is the target speaker reference. Re-run validation with the roles printed before model load. |
| Converted speech has the target reference words instead of the intended words. | User expected `target_wav` content to drive the output. | Explain that FreeVC preserves source utterance content; target/reference wav supplies speaker identity only. Use a TTS workflow if the desired content is text. |
| `tts_with_vc*` fails or produces no target voice. | Missing or invalid `speaker_wav`. | Require `speaker_wav` for TTS+VC. It is the target/reference speaker for the post-TTS conversion step. Validate with `scripts/validate_voice_conversion_inputs.py --mode tts-with-vc`. |
| Direct `voice_conversion*` errors with a missing voice converter. | A TTS model was loaded, but no FreeVC voice-conversion model is loaded. | Load `voice_conversion_models/multilingual/vctk/freevc24` for direct FreeVC, or use `tts_with_vc*` from a loaded TTS model so FreeVC can be loaded for the conversion step. |
| CLI run downloads or loads a TTS model instead of FreeVC. | `--model_name` was omitted or set to a `tts_models/...` name while using `--source_wav`/`--target_wav`. | Use `--model_name voice_conversion_models/multilingual/vctk/freevc24` for CLI voice conversion. Route full CLI syntax to [../../server-and-cli/SKILL.md](../../server-and-cli/SKILL.md). |
| Missing-file error before model load. | Source, target, speaker reference, or output parent path does not exist. | Use the validator helper. Create the output directory intentionally or pass the helper's create-directory option. Do not load models until paths are valid. |
| Invalid extension or unreadable audio header. | Non-wav input, mislabeled file, unsupported wav encoding, or missing audio codec support. | Prefer PCM wav inputs. If conversion/resampling is needed, route to [../../vocoder-and-audio-tools/SKILL.md](../../vocoder-and-audio-tools/SKILL.md). The validator can warn about headers without downloading models. |
| Unexpected sample rate in output. | FreeVC saves at its configured output sample rate, not the source sample rate. | For the released FreeVC config, expect `24000` Hz output. If downstream code needs another rate, resample as a separate audio-prep step in [../../vocoder-and-audio-tools/SKILL.md](../../vocoder-and-audio-tools/SKILL.md). |
| Quality is poor, muffled, or unstable. | Very short/noisy/clipped references, speech/music overlap, silence-heavy input, or source/target languages/acoustics outside the model's comfort zone. | Use clearer speech references, trim long silence, avoid music/noise, and test a short clip first. Do not claim dataset-level speaker embedding computation here; route that to [../../training-config-data/SKILL.md](../../training-config-data/SKILL.md). |
| Network/cache/model-file error while loading FreeVC. | Released model weights or config are not cached and network is unavailable or disallowed. | Stop and ask for download/cache approval or a prepared cache. The bundled conversion helper refuses model load unless `--allow-download` is explicit. |
| WavLM import/download/cache error. | FreeVC depends on WavLM feature extraction and may need transformer/model assets available in cache. | Verify the package environment has the transformer stack and an approved model cache. If network is forbidden, require pre-populated cache files before running conversion. |
| Speaker encoder download/import error. | Some FreeVC speaker-conditioning paths can require a speaker encoder asset or its dependencies. | Treat as a model/cache/dependency issue; do not retry blindly. Confirm network/cache approval and package imports first. |
| CUDA requested but unavailable. | `--device cuda` was used on a host without visible CUDA support or compatible PyTorch. | Retry on CPU for correctness checks, or switch to an approved CUDA environment. Warn that CPU conversion can be slow. |
| Process is very slow on CPU. | FreeVC and TTS+VC are neural model inference workflows. | Use short clips for tests, prefer GPU when available and approved, and separate validation/dry-run from model execution. |
| Output file already exists. | The destination path would be overwritten. | Pick a new output path or pass `--allow-overwrite` only after confirming replacement is intentional. |
| Multilingual or multi-speaker TTS route rejects `language` or `speaker`. | The selected TTS model either requires those IDs or does not support them. | Choose TTS model arguments in [../../inference-and-model-zoo/SKILL.md](../../inference-and-model-zoo/SKILL.md). Keep `speaker_wav` semantics for TTS+VC target voice here. |

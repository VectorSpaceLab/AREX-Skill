# Data and Benchmark Troubleshooting

Use this matrix when a dataset source, archive schema, or benchmark interpretation task fails. Do not solve model-loading or fine-tuning strategy problems here; route those to the sibling skills named in `SKILL.md`.

| Symptom | Likely cause | Check | Fix / response |
| --- | --- | --- | --- |
| `validate_dataset_schema.py --task chnsenticorp` says expected header `label`, `text_a` but found `label`, `text` | User has a ChnSentiCorp-like TSV from another preprocessing pipeline where the text column was renamed | Inspect the first line of each TSV member; run the validator with a small `--max-rows` to confirm the exact member/header failure | Rename `text` to `text_a` or export a new TSV with the exact two columns. Keep tab delimiter and binary `0`/`1` labels. |
| ChnSentiCorp rows are rejected even though the header is correct | Wrong delimiter, empty text field, labels outside `0`/`1`, or quoted TSV generated with embedded newlines that do not match the repository fixture style | Open a failing row number from validator output; verify it has one tab before non-empty text | Re-export as UTF-8 TSV with columns `label<TAB>text_a`; preserve review text after the first tab; map labels to `0` and `1`. |
| Weibo CSV fails on rows that contain commas or URLs | The file was parsed or generated by naive comma splitting instead of CSV rules, or the archive is not the expected Weibo sentiment CSV | Use the bundled validator; it uses Python `csv` and should accept commas in quoted fields if the CSV is valid | Re-export with standard CSV quoting and exact header `label,review`; do not remove microblog punctuation, hashtags, mentions, or URLs merely to satisfy parsing. |
| PeopleDaily validation reports row shape failures | Data is not in character-level BIO format, spaces were removed, or a word-level NER format was supplied | Check failing lines: each non-empty row must be exactly one Unicode character and one tag separated by whitespace | Convert to character-level rows `char TAG`; keep blank lines between sentences. |
| PeopleDaily validation reports unexpected tags | Tag set differs from the bundled PeopleDaily fixture, such as `B-MISC`, lowercase tags, or bare entity names | Compare tags against `O`, `B-PER`, `I-PER`, `B-ORG`, `I-ORG`, `B-LOC`, `I-LOC` | Map tags only if semantically correct; otherwise treat it as a different NER dataset and document the new tag vocabulary outside this validator. |
| User expects strict BIO transition validation for PeopleDaily | The repository fixture contains BIO-style tags but also has standalone `I-*` rows after sentence boundaries; a strict transition check would reject known bundled data | Run validator and note it checks row shape plus tag vocabulary, not transition legality | If the downstream library requires strict BIO transitions, perform a separate conversion/repair step after schema validation and report that it is a task-specific preprocessing decision. |
| `LCQMC` or `BQ Corpus` is missing from the repository | Copyright restrictions; repository data READMEs only provide external pointers and say direct links cannot be provided | Read the dataset-reference entry | Provide the original ICRC source URL and say the user must search GitHub or contact the original owner. Do not create a downloader or redistribute data. |
| `CMRC 2018`, `DRCD`, `XNLI`, `MSRA NER`, or `THUCNews` is missing from local files | These are source-pointer-only or large external datasets in this repository | Check dataset-reference availability class | Provide the source pointer and expected task/metric; ask the user for their local copy if schema conversion is needed. |
| User asks for CJRC test data or treats CJRC numbers as official final results | The repository evidence states the experiment test set is in-house and cannot be provided; the README says the used data is not identical to the official one | Check the benchmark-reference caveat | State the in-house caveat and avoid presenting the numbers as official final benchmark targets. |
| DRCD text looks wrong after loading | Traditional Chinese data decoded or converted incorrectly, or downstream tool assumes simplified Chinese | Inspect a few raw lines and confirm UTF-8 decoding; confirm whether the user's pipeline performs script conversion | Preserve Traditional Chinese unless intentionally converting. For model choice on Traditional Chinese, route to `../task-selection-and-finetuning/SKILL.md`. |
| XNLI label names do not match exactly | Some sources use `contradiction`; the Chinese README text says `contradictory` | Inspect the downloaded XNLI source format | Normalize labels consistently for the chosen training script; do not infer labels from benchmark scores. |
| User expects included zips for every benchmark dataset | The repository includes only selected fixture archives and README source pointers | List archive members or consult dataset-reference | Explain that full downloads remain user responsibility; the bundled validator supports only ChnSentiCorp, Weibo, and PeopleDaily archives. |
| Benchmark result is lower than the table | Random seed, batch size, preprocessing, wrong split, hyperparameters, domain, or code mismatch | Verify dataset schema first; then route model/fine-tuning checks to `../task-selection-and-finetuning/SKILL.md` | Treat table values as empirical references. Recheck batch size and average-vs-max interpretation before claiming reproduction failure. |
| User wants a script to download all datasets | Unsafe/inappropriate for copyright-restricted and large external sources | Check requested datasets against availability rules | Decline downloader creation; provide source pointers and constraints only. A local schema checker is allowed after the user supplies data. |

## Stop conditions

Stop and ask for user-supplied data or permission when:

- The needed dataset is source-pointer-only or copyright-restricted.
- The user asks for a full dataset download, redistribution, credential use, or scraping workaround.
- The supplied local archive has a schema that intentionally differs from the three supported validators and cannot be safely repaired by column renaming or delimiter correction.

## Quick validation commands

From this sub-skill directory:

```bash
python scripts/validate_dataset_schema.py --help
python scripts/validate_dataset_schema.py --task chnsenticorp --archive <chnsenticorp.zip> --max-rows 100
python scripts/validate_dataset_schema.py --task weibo --archive <weibo.zip> --max-rows 100
python scripts/validate_dataset_schema.py --task peopledaily --archive <peopledaily.zip> --max-rows 100
```

Use `--max-rows 0` for a full scan. The script performs no network access, checkpoint downloads, training, or destructive writes.

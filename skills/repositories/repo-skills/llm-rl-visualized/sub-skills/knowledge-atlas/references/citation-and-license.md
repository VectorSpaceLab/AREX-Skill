# Citation and license

## Reuse rules
- Non-commercial use only.
- If you use the materials online, keep the embedded author and repo attribution already present in the images.
- If you use the materials in a paper, book, or other formal publication, cite the project in the reference section using the formats below. In that case, embedded author text in the image may be removed.

## Recommended citation

### Chinese reference format
```text
余昌叶. 大模型算法：强化学习、微调与对齐[M]. 北京: 电子工业出版社, 2025. https://github.com/changyeyu/LLM-RL-Visualized
```

### English reference format
```text
Yu, Changye. Large Model Algorithms: Reinforcement Learning, Fine-Tuning, and Alignment. Beijing: Publishing House of Electronics Industry, 2025. https://github.com/changyeyu/LLM-RL-Visualized
```

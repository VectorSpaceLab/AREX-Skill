# T5 embedder notes

The text-conditioned path relies on `language/t5.py` and the `T5Embedder` helper.

## Supported model names
- `t5-v1_1-xxl`
- `t5-v1_1-xl`
- `flan-t5-xl`

## Important behaviors
- The helper can use a local cache directory or download the model files into a cache tree.
- Caption preprocessing is applied twice in the text-conditioned training and sampling flow.
- The sampling path can reorder embeddings for left-padding behavior; the bundled `--no-left-padding` flag disables that extra rearrangement.
- `extract_t5_feature.py` writes per-item `.npy` feature files keyed by the source JSONL file name and line index.

## Common cache expectations
- Use a stable cache root and keep the T5 cache separate from generated samples.
- A missing local cache usually means the text-conditioned workflow cannot start.
- A short or truncated caption variant is valid only when the training recipe explicitly expects it.

## Failure signals
- Missing model cache or download failure.
- Wrong `--t5-model-type` value.
- Shape mismatch between cached features and the caption embedding layout expected by the model.
- Prompt truncation errors when the sample or cache path comes from the wrong stage.

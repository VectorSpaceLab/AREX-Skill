# Muzic Project Map

Use this map to identify the closest Muzic workflow before reading a detailed sub-skill. The repository is a collection of research projects; dependency and data assumptions differ by row.

| Project | Main task | Typical inputs | Typical outputs | Runtime family | Owner |
|---|---|---|---|---|---|
| MusicBERT | Symbolic music understanding with OctupleMIDI, masked pretraining, melody completion, accompaniment suggestion, genre/style classification | Lakh MIDI zip, PiRhDy datasets, TOPMAGD/MASD mappings, OctupleMIDI text, Fairseq binarized data, checkpoints | pretraining/fine-tuned checkpoints, evaluation metrics | Python 3.6-era Fairseq/Torch; CUDA for train/eval | [music-understanding-retrieval](../sub-skills/music-understanding-retrieval/SKILL.md) |
| PDAugment | Data augmentation for automatic lyrics transcription using pitch and duration adjustment | LibriSpeech-like WAV/metadata/phoneme/alignment data, FreeMidi-style MIDI corpus, frequency JSON, output directories | duration-adjusted, pitch-adjusted, and combined augmented audio/data | CPU preprocessing plus ffmpeg/MFA/system deps; corpus-scale writes | [music-understanding-retrieval](../sub-skills/music-understanding-retrieval/SKILL.md) |
| CLaMP | Contrastive language-music retrieval, semantic music search, zero-shot classification, similar-music recommendation | MusicXML `.mxl` query/key files, text query/key files, model name, `top_n` | ranked retrieval/classification results | Torch/Transformers, Hugging Face checkpoint download; CUDA optional | [music-understanding-retrieval](../sub-skills/music-understanding-retrieval/SKILL.md) |

## Choosing between overlapping projects

- Choose CLaMP for text/music retrieval or zero-shot classification over symbolic scores.
- Choose MusicBERT for symbolic music understanding and classification/fine-tuning, not generation.
- Choose DeepRapper when the output is rap lyrics; choose SongMASS/TeleMelody/ReLyMe/ROC when the output is melody tied to lyrics.
- Choose GETMusic for adding or infilling instrument tracks in an existing MIDI.
- Choose MuseCoco for text-to-symbolic-music control via attributes.
- Choose Museformer or MeloForm for long-range structure/form modeling when text prompts are not the primary control.
- Choose EmoGen when the primary control variable is emotion quadrant.
- Choose MusicAgent when the user wants an LLM agent to pick and call music tools rather than a single model pipeline.

# Qwen2.5-VL detection formats

Qwen2.5-VL uses a fenced JSON list for object-detection outputs.

## Prefix prompt

The prefix formatter emits a direct instruction that names the classes and asks for JSON coordinates:

```text
Outline the position of crate, forklift. Output all the coordinates in JSON format.
```

The exact wording is generated by `detections_to_prefix_formatter(...)` and always uses the class names you pass in.

## Suffix format

The suffix formatter returns a fenced JSON code block whose body is a JSON array of objects:

```json
[
  {"bbox_2d": [12, 8, 44, 26], "label": "crate"},
  {"bbox_2d": [50, 10, 80, 30], "label": "forklift"}
]
```

Rendered as a model target, that becomes:

    ```json
    [
    	{"bbox_2d": [12, 8, 44, 26], "label": "crate"},
    	{"bbox_2d": [50, 10, 80, 30], "label": "forklift"}
    ]
    ```

Each object must contain:

- `bbox_2d`: `[x1, y1, x2, y2]` integer pixel coordinates
- `label`: the class name as a string

## Pixel-size alignment

The suffix formatter first calls `qwen_vl_utils.smart_resize(...)` with the current image size and the selected `min_pixels` / `max_pixels` bounds. It then rescales each box from original image coordinates into that resized input space and casts the coordinates to integers.

That means:

- the suffix coordinates are not normalized floats;
- the coordinates are not in the original image resolution;
- the same `min_pixels` / `max_pixels` pair must be used everywhere you train, load, generate, and parse.

If you change the pixel bounds in one place and not another, parsing can drift even when the labels are correct.

## Round-trip parsing

When you want to compare generated detections with targets, parse the strings with `sv.Detections.from_vlm(...)` using `sv.VLM.QWEN_2_5_VL` and supply both `input_wh` and `resolution_wh`.

Typical pattern:

```python
from qwen_vl_utils import smart_resize
import supervision as sv

image_w, image_h = image.size
input_h, input_w = smart_resize(height=image_h, width=image_w, min_pixels=MIN_PIXELS, max_pixels=MAX_PIXELS)

parsed = sv.Detections.from_vlm(
    vlm=sv.VLM.QWEN_2_5_VL,
    result=generated_suffix,
    input_wh=(input_w, input_h),
    resolution_wh=(image_w, image_h),
    classes=coco_dataset.classes,
)
```

## What to keep in sync

- The class ordering in the prefix.
- The class labels in the suffix.
- The `min_pixels` / `max_pixels` pair.
- The `smart_resize(...)` bounds used at load time and inference time.

# DeepMedic model-config contract

This reference is an operating summary of the 0.8.4 configuration parser and
network builder. The native parser reads a Python script with
`ModelConfig(abs_path_to_cfg)`. `Config` stores top-level assignments and
`ModelParameters(log, cfg)` resolves defaults, validates selected fields, and
prepares the argument list passed to `Cnn3d.make_cnn_model(...)`. The config
file is executable Python syntax, not JSON or an INI file. Use only trusted
files with the native loader; `scripts/inspect_model_config.py` is the safe,
static alternative.

## Field names

| Config field | Default / shape | Effect |
|---|---|---|
| `modelName` | `"deepmedic"` | Checkpoint/model naming label. |
| `folderForOutput` | No parser default; required by config intent | Output-folder setting used by the wider run configuration. It is retained by `ModelConfig` but is not consumed by `ModelParameters`' architecture arguments. |
| `numberOfOutputClasses` | Required positive task count | Number of output classes **including background**; the final FC layer has this many feature maps. Binary foreground/background therefore uses `2`. |
| `numberOfInputChannels` | Required, greater than zero | Channels per input segment, normally one per modality/sequence. Must match each channel manifest. |
| `numberFMsPerLayerNormal` | Required non-empty list | One positive feature-map count per normal-pathway convolution. List length is the normal depth. |
| `kernelDimPerLayerNormal` | Required list of 3-vectors | One `[x,y,z]` kernel per normal layer; source checks one 3-vector per FM entry. Odd positive kernels are the tested convention. |
| `padTypePerLayerNormal` | `['VALID'] * normal_depth` | Per-layer convolution padding. The implementation recognizes `VALID`/`valid`/`none`, `MIRROR`/`mirror`, and `ZERO`/`zero` (other values are passed to TensorFlow and may fail). |
| `layersWithResidualConnNormal` | `[]` | One-based layer numbers whose output receives a residual from the input of the previous block. Layer `1` is forbidden. |
| `lowerRankLayersNormal` | `[]` | One-based normal layers built with the low-rank convolution block. The current parameter code assigns rank `2`. |
| `useSubsampledPathway` | `False` | Enables one or more low-resolution paths. When false, all subsampled values are disregarded and no subsampled input is required. |
| `numberFMsPerLayerSubsampled` | Mirrors normal path | Flat list is wrapped as one path; nested lists describe multiple paths. All nested FM lists must have the same depth. Missing extra paths are copied from the previous FM list. |
| `kernelDimPerLayerSubsampled` | Mirrors normal kernels when depth matches | One shared kernel list is used for every subsampled path. If supplied, it must have one 3-vector per subsampled layer and its receptive field must equal the normal field. |
| `padTypePerLayerSubsampled` | `['VALID'] * subsampled_depth` | Padding list shared by active subsampled paths. Keep its length equal to the shared subsampled depth. |
| `subsampleFactor` | `[[3,3,3]]` | Flat `[x,y,z]` or nested list of 3-vectors. Each vector creates one parallel path; input is downsampled by that factor and repeated/center-cropped back before FC concatenation. |
| `layersWithResidualConnSubsampled` | Mirrors normal residual list | One-based residual layer numbers shared by every active subsampled path. |
| `lowerRankLayersSubsampled` | Mirrors normal lower-rank list | One-based lower-rank layer numbers shared by every active subsampled path. |
| `numberFMsPerLayerFC` | `[]` | Hidden FC-path feature-map counts only; the classifier is appended automatically. |
| `kernelDimPerLayerFC` | `[[1,1,1]]` repeated for hidden layers plus classifier | Must have exactly hidden-layer count + 1 vectors. The last vector belongs to the classifying convolution. |
| `padTypePerLayerFC` | `['VALID'] * (hidden + 1)` | One padding value per hidden/classification FC convolution. |
| `layersWithResidualConnFC` | `[]` | One-based residual points in the FC path. FC lower-rank layers are not generated by `ModelParameters`. |
| `segmentsDimTrain` | Required 3-vector | High-resolution input segment for training. Source checks it against the normal-path receptive field. |
| `segmentsDimVal` | Normal receptive field | Validation segment; source default is exactly the normal receptive field. |
| `segmentsDimInference` | Training dimensions | Inference segment; larger values improve throughput if memory allows. |
| `dropoutRatesNormal` | `[]` | Dropout rates applied before each normal convolution. If non-empty, keep one rate per normal layer. |
| `dropoutRatesSubsampled` | `[]` | Same contract for the shared subsampled depth. |
| `dropoutRatesFc` | `0.0` for first FC input and `0.5` for remaining FC entries by default | One rate per hidden FC layer plus classifier; the implementation does not robustly validate length. |
| `convWeightsInit` | `['fanIn', 2]` | `['normal', std]` or `['fanIn', scale]`; the first value must be `normal` or `fanIn`. |
| `activationFunction` | `'prelu'` | One activation for convolution blocks: `linear`, `relu`, `prelu`, `elu`, `selu`. `selu` is accepted by parameter validation but its layer implementation raises `NotImplementedError` when applied. |
| `rollAverageForBNOverThatManyBatches` | `60` | Positive value enables the custom rolling-average BN machinery; value <= 0 disables it. BN is applied to the first layer only when enabled and then before every later block. |

Commented-out fields are absent and receive defaults. Two deprecated names,
`initializeClassic0orDelving1` and `relu0orPrelu1`, are explicitly rejected;
use `convWeightsInit` and `activationFunction` instead.

## Geometry and feature-map flow

A convolution block applies, in order, input bias or BN, activation, dropout,
optional pooling, then convolution. The configured FM count is the convolution
output count. The first normal and subsampled convolution each consume
`numberOfInputChannels`. The normal path is built first. Each active
subsampled path uses its own factor but the shared subsampled kernels/padding;
its final maps are upsampled by repetition and clipped to the normal-path
output shape. The FC path then receives the channel concatenation:

```
FC input FMs = last normal FMs + sum(last FMs of active subsampled paths)
FC hidden FMs = numberFMsPerLayerFC
classifier FMs = numberOfOutputClasses
```

The final target block adds a bias and applies softmax across the feature-map
(class) axis. The class count must therefore agree with labels and checkpoints.

For a stride-1 path with kernels `k1 ... kn`, the source helper computes the
receptive field per dimension as:

```
RF[d] = 1 + (k1[d]-1) + ... + (kn[d]-1)
```

The source segment guard compares only this normal-path RF to each of
`segmentsDimTrain`, `segmentsDimVal`, and `segmentsDimInference`. It does not
include FC kernels. The runtime layer geometry still applies every FC kernel;
with `VALID` FC kernels, the output can shrink further. For a rough full-model
check, add every FC `(kernel[d]-1)` to the normal RF and calculate output
sizes with the configured padding. `VALID` gives `input-kernel+1`; non-VALID
`ZERO`/`MIRROR` is implemented as dimension-preserving for the tested odd
kernels. Even kernels are not thoroughly tested.

The normal and subsampled convolution kernels must have equal RF lists, not
merely equal scalar depth. If normal kernels are eight `[3,3,3]` vectors, the
RF is `[17,17,17]`. A two-path `[3,3,3]` mirror therefore has the same RF;
changing a subsampled layer count requires compensating kernel dimensions.

## Residual and lower-rank behavior

Config layer numbers start at 1, while the architecture argument uses zero-based
indices. A residual entry for layer `n` is attached to block index `n-1`; the
pathway adds that block's output to the input of the preceding block. The
helper center-crops the earlier spatial tensor to the deeper tensor's spatial
shape, then pads or truncates channels before addition. There is no learned
1x1 projection. Do not use layer 1, and after deleting/reordering layers,
re-audit every residual index and spatial shape.

A lower-rank entry selects `LowRankConvBlock`. The implementation splits output
maps into three sub-convolutions along x/y/z (approximately one third each) and
concatenates their cropped outputs. The parameter builder supplies rank 2 for
selected normal/subsampled layers and never selects FC lower-rank blocks. This
can reduce convolution parameter/activation cost, but use it only after the
checks in [troubleshooting.md](troubleshooting.md), because this 0.8.4 path has
known edge cases.

## Authoring and resizing checklist

- Count labels with background and set `numberOfOutputClasses` accordingly.
- Count modalities/channels in the manifests and set
  `numberOfInputChannels` identically.
- Make FM and kernel lists the same depth; use 3-vector kernels.
- Compute normal RF before selecting all segment dimensions.
- If active, normalize every subsample factor to a 3-vector and make the
  subsampled RF exactly equal to the normal RF.
- Keep FC kernel/padding/dropout list lengths at hidden count + 1.
- Keep padding, residual, lower-rank, and dropout lists aligned with their
  paths. Prefer odd kernels and odd positive subsampling factors.
- Reduce FMs or remove paths before reducing segment dimensions; re-check
  residual indices and checkpoint compatibility after each change.
- Run the bundled inspector and retain its output with the model authoring
  notes; it does not import TensorFlow or launch training.

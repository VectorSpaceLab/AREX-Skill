# Model and reference assets

The pretrained inference workflows rely on two kinds of files:

1. Repo-bundled helper assets under `Utils/`.
2. Publicly downloaded pretrained model and reference-audio assets.

## Bundled helper assets

These live in the repository checkout and are used by both inference notebooks:

| Asset | Purpose |
| --- | --- |
| `Utils/ASR/config.yml` | ASR/text-aligner configuration |
| `Utils/ASR/epoch_00080.pth` | Pretrained text-aligner checkpoint |
| `Utils/JDC/bst.t7` | Pretrained pitch extractor |
| `Utils/PLBERT/config.yml` | PL-BERT configuration |
| `Utils/PLBERT/step_1000000.t7` | PL-BERT checkpoint |

The inference scripts read these paths from the family config files.

## External pretrained model assets

### LJSpeech

Required local targets after download:

- `Models/LJSpeech/config.yml`
- `Models/LJSpeech/epoch_2nd_00100.pth`

Public source:

- LJSpeech model tree: https://huggingface.co/yl4579/StyleTTS2-LJSpeech/tree/main

### LibriTTS

Required local targets after download:

- `Models/LibriTTS/config.yml`
- `Models/LibriTTS/epochs_2nd_00020.pth`

Public source:

- LibriTTS model tree: https://huggingface.co/yl4579/StyleTTS2-LibriTTS/tree/main

### LibriTTS reference audio

The LibriTTS notebook uses a separate reference-audio bundle.

Download:

- `reference_audio.zip`: https://huggingface.co/yl4579/StyleTTS2-LibriTTS/resolve/main/reference_audio.zip

After downloading, extract the archive so the notebook-style examples can read
wav files from `Demo/reference_audio/`.

## What the checker expects

The asset checker treats these conditions as readiness signals:

- Helper assets in `Utils/` exist.
- The selected model-family files exist under `Models/`.
- If reference-audio checking is enabled, `Demo/reference_audio/` exists and
  contains `.wav` files.
- If phonemizer checking is enabled, Python `phonemizer`, an `espeak` or
  `espeak-ng` binary, and NLTK tokenization data are available.

## Notes

- The repository is a source checkout, not an installable Python package.
- The public model downloads are separate from the repo checkout and are not
  bundled here.
- The LibriTTS reference archive is required for the zero-shot and style-
  transfer examples, but it is not generated by the code.

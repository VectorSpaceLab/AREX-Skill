# Ontology and Interface Troubleshooting

Use this when a custom model, ontology, composed workflow, or embedding workflow fails before dataset writing.

| Symptom | Likely cause | Recovery |
|---|---|---|
| Cannot instantiate a custom class | Abstract `predict`, `label`, `train`, `embed_image`, or `embed_text` method not implemented | Implement every abstract method required by the chosen base/target class; run `check_interfaces.py` for a safe pattern. |
| `AttributeError: ... ontology` | Subclass called `BaseModel.__init__` but did not assign `self.ontology` | Set `self.ontology = ontology` in the concrete subclass constructor. |
| `ValueError: Ontology is empty` | `CaptionOntology` received an empty mapping | Provide at least one prompt/class pair. |
| Prompt or class lookup error | Prompt/class string is not present in `promptMap` | Print `ontology.prompts()` and `ontology.classes()`; fix spelling and class ordering. |
| Dataset writer creates wrong class ids | `predict` returns `class_id` values not aligned to `ontology.classes()` | Map model-native labels to ontology class indices before returning `supervision.Detections` or `Classifications`. |
| `record_confidence=True` fails downstream | Dummy/custom detector omitted confidence scores | Include `confidence=np.array([...])` in `supervision.Detections` or disable confidence recording. |
| Docs class name not importable | Docs mention stale `CustomDetectionModel` or `CombinedDetectionModel` names | Use `ComposedDetectionModel` from `autodistill.core.composed_detection_model` for this snapshot. |
| Composed prediction overwrites `temp.jpeg` | `ComposedDetectionModel` writes a fixed temp file while classifying crops | Run in an isolated working directory or modify/wrap the concrete model for unique temporary paths. |
| Set-of-marks branch raises unsupported-model exception | Classification model lacks `set_of_marks` | Use normal crop classification or choose a plugin exposing `set_of_marks`. |
| Text classification labeling writes nothing | Core `TextClassificationBaseModel.label` is a stub | Use a concrete text plugin or implement JSONL labeling yourself. |
| Embedding comparison looks wrong | Embeddings were generated by a different model/preprocessing or wrong shape | Recompute embeddings with the same model and check vector dimensions with a tiny example. |

## Debug Order

1. Validate ontology round trips.
2. Instantiate the class and verify required attributes/methods.
3. Run one `predict` on a tiny input and inspect return type and class ids.
4. If using inherited `.label`, use [dataset labeling](../../dataset-labeling/SKILL.md) to validate output layout.
5. Only then add plugin downloads, GPU execution, target training, or Roboflow upload.

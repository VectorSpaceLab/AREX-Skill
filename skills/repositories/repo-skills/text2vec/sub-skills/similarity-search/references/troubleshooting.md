# Troubleshooting

| Symptom | Likely cause | Fix |
|---|---|---|
| `Similarity()` tries to download a BERT model or fails with a model/cache error. | The default public model is not already present in the environment. | Pass `model_name_or_path` or `--model-name` as a local/cached model directory. If downloads are forbidden, use vector-only scoring or BM25. |
| `get_scores(..., only_aligned=True)` still returns a 2-D matrix. | The API returns matrices. For BERT, `only_aligned` does not avoid the full cross-product; for Word2Vec it fills only the diagonal but still returns a matrix. | For aligned file rows, call `get_score` per pair or use `scripts/score_pairs.py`. If you already have a matrix, use the diagonal only for aligned pairs. |
| A cosine score is negative. | Cosine similarity is in `[-1, 1]`, not `[0, 1]`. | Interpret larger as more similar. A negative score means vectors point in opposite directions. Do not clamp unless your downstream metric explicitly requires it. |
| BM25 scores do not look like cosine scores. | BM25 scores are lexical retrieval scores, not normalized semantic cosine values. | Compare BM25 scores only within the same query/corpus setup. Do not mix BM25 thresholds with dense cosine thresholds. |
| Empty corpus raises an error or returns no hits. | BM25 and dense search require at least one corpus row. | Validate corpus files before search. Remove blank-only lines or add documents. |
| Empty query returns zero/empty output. | Similarity returns `0.0` for blank pairs; retrieval has no useful tokens or vectors for an empty query. | Filter or report blank queries before scoring. |
| `top_k` is larger than the corpus size. | There are fewer documents than requested hits. | Treat output length as `min(top_k, corpus_size)`. The helper scripts reject non-positive `top_k` and return only available corpus rows. |
| Chinese BM25 misses expected terms or all scores are zero. | The BM25 wrapper segments raw text with Jieba; domain-specific words may be split differently than expected. | Add domain words before building a custom tokenizer, or pre-tokenize and use the low-level `BM25Okapi` path. For the bundled script, keep corpus/query as raw text and inspect tokenization if rankings look wrong. |
| Dense search fails with a dtype or shape error. | `cos_sim` and `semantic_search` expect numeric vectors with consistent dimensions. A list of strings, ragged lists, or mismatched dimensions will fail. | Ensure embeddings are 1-D numeric arrays per row and all rows have the same dimension. JSON vector fields should be arrays like `[0.1, 0.2]`, not quoted prose. |
| `semantic_search` returns `corpus_id`, not original document IDs. | The API indexes into the corpus embedding matrix by row number. | Map `corpus_id` back to your corpus rows. Preserve row order when loading text and embeddings. |
| Dense search from JSON list-of-lists fails in custom code. | The package utility handles NumPy arrays and tensors more reliably than raw nested Python lists. | Convert loaded embeddings to a NumPy array or torch tensor before calling `semantic_search`. The bundled script does this conversion. |
| Dot-product scores disagree with `cos_sim`. | `cos_sim` normalizes each row before multiplying; raw dot product depends on vector magnitude. | Use `cos_sim`/`semantic_search` for cosine. If embeddings are already normalized, dot product and cosine may match; if not, they will not. |
| Pre-normalized embeddings produce the same dense ranking as raw embeddings. | `cos_sim` normalizes internally, so additional normalization often does not change cosine rankings. | Keep normalization consistent across pipelines. Do not compare raw-dot and cosine thresholds. |
| `score_pairs.py` says vectors or IDs are missing. | The input columns do not match the defaults: `embedding1`, `embedding2`, `id1`, `id2`. | Pass `--embedding1-column`, `--embedding2-column`, `--id1-column`, or `--id2-column` to match your file headers. |
| `search_corpus.py --mode dense` asks for embeddings or a model. | Dense search needs either precomputed embeddings or a model to encode texts. | Provide `--corpus-embeddings-file` and `--query-embeddings-file` for no-network search, or pass `--model-name` when model use is allowed. |
| Word2Vec or WMD setup fails. | Word-vector scoring needs optional model files and dependencies. | Use BERT cosine with a cached/local model, vector-only cosine, or BM25 unless Word2Vec assets are available. |

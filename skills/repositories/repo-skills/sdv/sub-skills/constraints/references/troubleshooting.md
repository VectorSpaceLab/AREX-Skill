# Constraint troubleshooting

| Symptom | Likely cause | Fix |
| --- | --- | --- |
| `Constraints must be a list of sdv.cag objects.` | Passed a single object, `None`, or a non-list container to `add_constraints`. | Wrap current CAG or programmable objects in a list: `synthesizer.add_constraints([constraint])`. |
| Warning says older dictionary-style constraints are ignored. | Passed legacy dictionaries such as `constraint_class` / `constraint_parameters` to current `add_constraints`. | Translate to `sdv.cag` objects or load current JSON with `load_constraints`; do not rely on ignored entries. |
| `Metadata contains more than 1 table but no ``table_name`` provided.` | A one-table CAG constraint is applied to multi-table metadata without target table. | Add `table_name='target_table'` to the constraint or use a multi-table programmable constraint. |
| `Table 'X' missing from metadata` or `Table 'X' is missing columns ...`. | Misspelled table/column name or metadata was not updated before adding the constraint. | Fix metadata/table/column names first, then recreate the constraint. Route metadata construction to data-preparation. |
| `Column ... has an incompatible sdtype ...`. | Constraint and metadata sdtypes do not match the required type. | Use compatible sdtypes: `FixedCombinations` boolean/categorical; `Inequality` and `Range` all numerical or all datetime; `FixedIncrements` numerical. |
| Error says columns must have the same sdtype. | Bound columns for `Inequality` or `Range` mix numerical, datetime, id, categorical, or unknown sdtypes. | Update metadata so all participating columns share the same valid sdtype, or choose a different constraint. |
| Error says a constrained column is a primary key. | CAG constraints cannot transform primary-key columns. | Do not constrain primary keys; choose non-key columns or change metadata ownership only if the data model is truly different. |
| Error says columns are part of a column relationship. | A constraint would remove or replace columns used by a metadata column relationship. | Avoid constraining relationship columns, or revise the relationship metadata before adding the constraint. |
| `Data is not valid for the '...' constraint` during add/fit. | Real training data violates the constraint. | Inspect the printed invalid rows, clean or filter real data, relax `strict_boundaries`, or use a constraint that matches actual business rules. |
| Sample validation error says requirement is not met for row indices. | Synthetic rows violated the constraint, often because a custom reverse transform or `is_valid` is inconsistent. | Call `validate_constraints` on a small sample, inspect the named rows, and verify transform/reverse/is_valid agree on the same rule. |
| Custom `is_valid_fn` error: did not produce exactly 1 value per row. | Legacy custom `is_valid_fn` returned the wrong length. | Return `pd.Series(boolean_values, index=data.index)` with length exactly `len(data)`. |
| Custom `is_valid` error: returned unsupported type; must be `pandas.Series`. | Legacy custom function returned a list, NumPy array, scalar, or DataFrame. | Wrap booleans as `pd.Series(..., index=data.index)` and preserve one value per row. |
| `Missing parameter transform_fn` or `Missing parameter reverse_transform_fn`. | Legacy custom factory received only one side of the transform pair. | Provide both `transform_fn` and `reverse_transform_fn`, or provide neither. |
| `Transformation did not produce the same number of rows` or reverse-transform row-count error. | Custom transform dropped/added rows or returned an object with mismatched shape. | Preserve row count in both directions. If filtering is required, express it in `is_valid` instead of transform. |
| Transform raises `FunctionError`. | Custom function signature or body failed under SDV's call pattern. | Use signatures `(column_names, data, **kwargs)`, return a DataFrame, and test the function directly on a small frame. |
| `Cannot convert constraint to dictionary because required parameters ... are not saved as attributes`. | Programmable constraint `__init__` parameters were not stored on `self`. | Save every constructor parameter as `self.param` or `self._param` before calling `get_constraint_dict` or `get_constraints(filepath)`. |
| `Unknown constraint_class` while loading JSON. | JSON `class_name` is misspelled, legacy-shaped, or not importable from the current CAG loading surface. | Use current shape `{"class_name": "Inequality", "parameters": {...}}`; replace unknown classes or instantiate custom programmable constraints directly. |
| `load_constraints` returns fewer constraints than the JSON file. | Unknown or invalid entries were warned and skipped. | Capture warnings, compare counts, and do not continue until every required constraint is loaded or intentionally removed. |
| `Cannot save constraints to file because ... already exists.` | `get_constraints(filepath)` refuses to overwrite. | Choose a new file path or delete/rename the old file deliberately before saving. |
| `set_constraints` warning says it is deprecated. | Using synthesizer-level legacy loader. | Prefer `constraints = load_constraints(filepath)` then `synthesizer.add_constraints(constraints)`. |
| `Cannot set_constraints since constraints have already been applied.` | Existing constraints are present on the synthesizer. | Start a fresh synthesizer, or keep the existing constraints and add more with `add_constraints` if compatible. |
| `SingleTableProgrammableConstraint cannot be used with multi-table metadata... table_name ...`. | DataFrame-style programmable constraint targets one table but did not set `table_name`. | Add `self.table_name = 'target_table'` in `__init__`, or use `ProgrammableConstraint` with dictionary-shaped methods. |
| Multi-table synthesizer says a built-in is missing required `table_name`. | A single-table CAG constraint was routed into a multi-table synthesizer without a table. | Recreate the constraint with `table_name`; ensure per-table constraints are ordered after true multi-table constraints when mixing both. |
| PAR synthesizer rejects overlapping constraints. | Two constraints act on the same column. | Remove or merge overlapping constraints before adding to PAR. |
| PAR synthesizer rejects mixed context and non-context columns. | One constraint spans both sequence context columns and varying sequential columns. | Split the rule or redesign sequence metadata so each constraint touches only context or only non-context columns. |
| Added constraints after fit but samples ignore them. | Constraints were attached after fitting and the synthesizer was not refit. | Refit before sampling. Treat the refit warning as mandatory for constrained output. |
| Deprecated scalar constraint warning. | Using `ScalarInequality`, `ScalarRange`, or legacy zero-bound wrappers. | Prefer synthesizer `enforce_min_max_values` for simple observed-bound enforcement, or use CAG/programmable constraints for explicit business rules. |

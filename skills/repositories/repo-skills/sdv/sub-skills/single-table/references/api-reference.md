# Single-Table API Reference

This reference covers the public SDV single-table synthesis surface. It assumes the data is already loaded as a pandas `DataFrame` and described by a single-table `Metadata` object.

## Imports

```python
from sdv.single_table import (
    GaussianCopulaSynthesizer,
    CTGANSynthesizer,
    TVAESynthesizer,
    CopulaGANSynthesizer,
    DayZSynthesizer,
)
from sdv.lite import SingleTablePreset
from sdv.sampling import Condition, DataFrameCondition
```

## Model Selection

| Need | Use | Notes |
| --- | --- | --- |
| Fast, classical, CPU-friendly baseline; native conditional sampling; learned marginal distributions | `GaussianCopulaSynthesizer` | Best first choice for small/medium tabular data, quick iteration, parameter inspection, and portability. |
| Neural tabular model for mixed data | `CTGANSynthesizer` | Uses `ctgan`/torch. Conditional public methods work through SDV's reject-sampling wrapper when the model cannot sample conditionally itself; rare conditions can be slow. |
| Variational autoencoder tabular model | `TVAESynthesizer` | Uses `ctgan`/torch. Same public sampling surface as CTGAN; no `locales` constructor argument. |
| CTGAN with GaussianCopula-style normalization for numerical columns | `CopulaGANSynthesizer` | Deep model plus `numerical_distributions` / `default_distribution`; exposes learned distributions after fit. |
| Create or validate DayZ parameter dictionaries | `DayZSynthesizer.create_parameters`, `DayZSynthesizer.validate_parameters` | In community SDV, constructing `DayZSynthesizer(...)` is not public and raises a `SynthesizerInputError`. |
| Legacy fast preset | `SingleTablePreset(metadata, name='FAST_ML')` | Deprecated. Prefer `GaussianCopulaSynthesizer(metadata, default_distribution='norm', enforce_rounding=False)`. |

## Constructors

| Class | Signature highlights |
| --- | --- |
| `GaussianCopulaSynthesizer` | `metadata, enforce_min_max_values=True, enforce_rounding=True, locales=['en_US'], numerical_distributions=None, default_distribution=None` |
| `CTGANSynthesizer` | `metadata, enforce_min_max_values=True, enforce_rounding=True, locales=['en_US'], embedding_dim=128, generator_dim=(256, 256), discriminator_dim=(256, 256), generator_lr=2e-4, generator_decay=1e-6, discriminator_lr=2e-4, discriminator_decay=1e-6, batch_size=500, discriminator_steps=1, log_frequency=True, verbose=False, epochs=300, pac=10, enable_gpu=True, cuda=None` |
| `TVAESynthesizer` | `metadata, enforce_min_max_values=True, enforce_rounding=True, embedding_dim=128, compress_dims=(128, 128), decompress_dims=(128, 128), l2scale=1e-5, batch_size=500, verbose=False, epochs=300, loss_factor=2, enable_gpu=True, cuda=None` |
| `CopulaGANSynthesizer` | CTGAN arguments plus `numerical_distributions=None, default_distribution=None`; `enable_gpu=True`, `cuda=None` |
| `DayZSynthesizer` | Constructor is enterprise-only in community SDV. Public class methods are `create_parameters(data, metadata, filepath=None)` and `validate_parameters(metadata, parameters)`. |
| `SingleTablePreset` | `metadata, name, locales=['en_US']`; only `FAST_ML` is available and emits a deprecation warning. |

### Distribution Options

For `GaussianCopulaSynthesizer` and `CopulaGANSynthesizer`, `numerical_distributions` maps metadata column names to one of: `norm`, `beta`, `truncnorm`, `uniform`, `gamma`, `gaussian_kde`. `default_distribution` defaults to `beta`. `gaussian_kde` is non-parametric, so parameter extraction can be unavailable.

## Common Synthesizer Methods

| Method | Applies to | Use |
| --- | --- | --- |
| `fit(data)` | Main synthesizers and preset | Validate metadata/constraints, preprocess, fit, and mark the synthesizer as fitted. |
| `preprocess(data)` | Main synthesizers | Validate and transform raw data to the processed model space. Use with the same synthesizer before `fit_processed_data`. |
| `fit_processed_data(processed_data)` | Main synthesizers | Fit directly on already processed data generated by this synthesizer. Do not pass raw data or processed data from another synthesizer. |
| `validate(data)` | Main synthesizers | Validate data against original metadata and synthesizer constraints before fitting. |
| `sample(num_rows, max_tries_per_batch=100, batch_size=None, output_file_path=None)` | Main synthesizers and preset | Generate rows. `output_file_path` periodically writes rows and must not already exist. |
| `sample_from_conditions(conditions, max_tries_per_batch=100, batch_size=None, output_file_path=None)` | Main synthesizers and preset | Generate rows that match `Condition` or `DataFrameCondition` objects. |
| `sample_remaining_columns(known_columns, max_tries_per_batch=100, batch_size=None, output_file_path=None)` | Main synthesizers and preset | Complete each row of a partial known-columns DataFrame. |
| `reset_sampling()` | Main synthesizers | Reset sampling/key generation state to the post-fit state. |
| `auto_assign_transformers(data)` | Main synthesizers | Fit the data processor enough to populate default RDT transformers. |
| `get_transformers()` | Main synthesizers | Return the current column-to-transformer mapping after `auto_assign_transformers` or `fit`. |
| `update_transformers(column_name_to_transformer)` | Main synthesizers | Replace selected transformers; if the synthesizer was already fitted, refit for changes to take effect. |
| `add_constraints(constraints)` | Main synthesizers | Attach constraint objects before fitting; accepts standard and programmable constraints. |
| `get_constraints(filepath=None)` | Main synthesizers | Return current constraints, or write a JSON file when `filepath` is provided and does not already exist. |
| `set_constraints(filepath)` | Main synthesizers | Deprecated JSON-load path. Fails if constraints are already applied; prefer constructing constraints and `add_constraints`. |
| `validate_constraints(synthetic_data)` | Main synthesizers | Check whether synthetic rows satisfy attached constraints. |
| `load_custom_constraint_classes(filepath, class_names)` | Main synthesizers | Register custom constraint classes for use by the data processor. |
| `save(filepath)` | Main synthesizers and preset | Serialize with cloudpickle. Saving an unfitted synthesizer is allowed but warns because sampling will fail until fitted. |
| `load(filepath)` | Class method on main synthesizers and preset | Deserialize and validate class/version compatibility. Use the same class used to save. |
| `get_info()` | Main synthesizers | Return class name, creation date, fit status, last fit date, and fitted SDV version. |
| `get_parameters()` | Main synthesizers and preset | Return constructor parameters except metadata. Deprecated `cuda` is normally removed in favor of `enable_gpu`. |
| `get_metadata(version='original'|'modified')` | Main synthesizers and preset | Return a copy of original metadata or metadata modified by constraints. |

## Sampling Condition Classes

| Class | Signature | Use |
| --- | --- | --- |
| `Condition` | `Condition(column_values, num_rows=1, table_name=None)` | Request `num_rows` rows matching a dict such as `{'room_type': 'DELUXE'}`. Prefer explicit keywords such as `Condition(column_values={'room_type': 'DELUXE'}, num_rows=25)`; for single-table sampling, omit `table_name`. |
| `DataFrameCondition` | `DataFrameCondition(dataframe, table_name=None)` | Request one output row per input condition row; useful for heterogeneous condition sets. |
| `MultiTableCondition` | `MultiTableCondition(conditions)` | Multi-table helper; route multi-table tasks to the multi-table sub-skill. |

Condition columns must be columns from the original fitted data/metadata and cannot be the primary key.

## Model-Specific Inspection

| Method | Applies to | Behavior |
| --- | --- | --- |
| `get_learned_distributions()` | `GaussianCopulaSynthesizer`, `CopulaGANSynthesizer` | After fit, returns `{column: {'distribution': name, 'learned_parameters': {...}}}` for modeled numerical columns. Raises before fit. |
| `get_loss_values()` | `CTGANSynthesizer`, `TVAESynthesizer`, `CopulaGANSynthesizer` | After fit, returns a copy of the model loss-values DataFrame. Raises `NotFittedError` before fit. |
| `get_loss_values_plot(title='CTGAN loss function')` | `CTGANSynthesizer`, `TVAESynthesizer`, `CopulaGANSynthesizer` | After fit, returns a Plotly line figure using generator/discriminator loss columns when available. |

## GPU and Persistence Notes

- `CTGANSynthesizer`, `TVAESynthesizer`, and `CopulaGANSynthesizer` accept `enable_gpu=True` by default. Set `enable_gpu=False` for deterministic CPU-only runs or models that must be loaded later on CPU-only hardware.
- `cuda` is deprecated. Do not pass both `cuda` and `enable_gpu` in new code; replace old `cuda=False` with `enable_gpu=False`.
- A deep model saved from a GPU-backed run can fail to load on a CPU-only machine; SDV reports this as a `SamplingError` and recommends sampling on the same GPU-enabled machine.

## DayZ Parameter Schema

`DayZSynthesizer.create_parameters(data, metadata, filepath=None)` returns a dict with `DAYZ_SPEC_VERSION: 'V1'` and `tables`. A table can include `num_rows` and `columns`. Column parameters can include `missing_values_proportion`; numerical columns can include `num_decimal_digits`, `min_value`, `max_value`; categorical columns can include `category_values`; datetime columns can include `start_timestamp`, `end_timestamp`.

Single-table DayZ parameters must not include relationships, must reference only tables/columns present in metadata, and must set missing-value proportions for key columns to zero.

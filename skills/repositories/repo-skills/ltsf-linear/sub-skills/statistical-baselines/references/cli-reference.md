# Statistical Baseline CLI Reference

This route covers the repository root `run_stat.py` entry point plus the baseline implementations in `models/Stat_models.py`.

## Execution contract

`run_stat.py` is an evaluation-only script even though it requires `--is_training 1`. It seeds Python `random`, PyTorch, and NumPy to `2021`, sets `args.use_gpu = False`, builds `Exp_Main` from `exp/exp_stat.py`, and calls `exp.test(setting)` once.

Run commands from the sub-skill directory or the repository root, and use the bundled wrapper with `--repo-root` and `--work-dir` when you want safer path handling.

```bash
python run_stat.py \
  --is_training 1 \
  --model_id exchange_rate_96_96 \
  --model Naive \
  --data custom \
  --root_path ./dataset/ \
  --data_path exchange_rate.csv \
  --features M \
  --seq_len 96 \
  --label_len 48 \
  --pred_len 96 \
  --des Exp \
  --itr 1
```

The same command can be generated by the bundled wrapper:

```bash
python scripts/run_stat_baselines.py \
  --model Naive --data custom --data-root dataset --data-path exchange_rate.csv \
  --features M --seq-len 96 --label-len 48 --pred-len 96 --des Exp --itr 1
```

## Model keys

| CLI value | Source implementation | Behavior | Practical note |
| --- | --- | --- | --- |
| `Naive` | `Naive_repeat` | Repeats the last observed value in each input window for all `pred_len` future steps. | Fastest baseline; source sweep notes call it Repeat-C / closest repeat. |
| `GBRT` | `GBRT` | For each batch item and channel, fits `sklearn.ensemble.GradientBoostingRegressor` on integer positions `0..seq_len-1` and predicts positions `seq_len..seq_len+pred_len-1`. | CPU-only and slower than Naive but usually feasible for small sampled comparisons. |
| `ARIMA` | `Arima` | Calls `pmdarima.auto_arima(seq)` per batch item and channel. | Extremely slow; use small `--sample` and small `--batch_size` first. |
| `SARIMA` | `SArima` | Calls `pmdarima.auto_arima(seq, seasonal=True, m=season)` per batch item and channel. | Slower than ARIMA; use very small `--sample`. |

`run_stat.py` imports `pmdarima` through `models/Stat_models.py` before argument parsing, so even `--help` and `Naive` runs fail if `pmdarima` is absent.

## Important arguments

| Argument | Required by source? | Default in source | Meaning / caveat |
| --- | --- | --- | --- |
| `--is_training` | yes | `1` | Required parser flag, but `run_stat.py` only calls `test()`. Use `1` to match source scripts. |
| `--model_id` | yes | `test` | Prefix in the generated setting string and output directories. Use dataset, sequence length, and prediction length for traceability. |
| `--model` | yes | `Autoformer` | Must be one of `Naive`, `GBRT`, `ARIMA`, `SARIMA` for this route. Other values raise a model lookup error in `exp/exp_stat.py`. |
| `--data` | yes | `ETTm1` | Dataset loader key. Use `ETTh1`, `ETTh2`, `ETTm1`, `ETTm2`, or `custom`. |
| `--root_path` | no | `./data/ETT/` | Directory containing `--data_path`. Source sweeps use `./dataset/`. |
| `--data_path` | no | `ETTh1.csv` | CSV file name under `--root_path`. |
| `--features` | no | `M` | `M`: multivariate to multivariate; `S`: univariate to univariate; `MS`: multivariate to univariate. |
| `--target` | no | `OT` | Required column for `S` and `MS`; ignored for multivariate `M` except by some dataset rearrangement logic. |
| `--seq_len` | no | `96` | Look-back window length. |
| `--label_len` | no | `48` | Kept for data-loader compatibility; statistical models do not consume decoder labels directly. |
| `--pred_len` | no | `96` | Forecast horizon. |
| `--sample` | no | `1` | Per-batch sampling fraction: source computes `max(int(sample * batch_size), 1)`, not a global dataset percentage. |
| `--batch_size` | no | `100` | Test dataloader batch size and denominator used by `--sample`. |
| `--num_workers` | no | `10` | DataLoader workers. Use `0` for synthetic smoke tests or constrained shells. |
| `--freq` | no | `h` | Time feature frequency. Common values include `h`, `t`, `d`, `w`, `m`, or compound strings like `15min`. |
| `--embed` | no | `timeF` | Only used to choose time feature encoding; not a statistical model embedding. |
| `--train_only` | no | `False` | Marked "Not implemented" in `run_stat.py`; only affects `Dataset_Custom` split sizing if passed through. |
| `--checkpoints` | no | `./checkpoints/` | Present for CLI compatibility; not used by statistical testing. |
| `--des` | no | `test` | Suffix in the setting string. Source sweeps use `Exp`. |
| `--itr` | no | `2` | Parsed for compatibility; `run_stat.py` does not loop over iterations. |

## Dataset loader notes

- `ETTh1` and `ETTh2` use the fixed-border hourly ETT loader and expect the full preprocessed ETT-hour CSV shape.
- `ETTm1` and `ETTm2` use the fixed-border minute ETT loader and expect the full preprocessed ETT-minute CSV shape.
- `custom` uses a ratio split: 70% train, 10% validation, 20% test. The CSV must contain `date`; all non-date columns are features for `M`/`MS`, and `target` is selected for `S`.
- For tiny synthetic checks, prefer `custom` with enough rows that the test split is longer than `seq_len + pred_len`.

## Output locations

`exp/exp_stat.py` writes relative to the current working directory of the Python process:

- `test_results/<setting>/`: periodic PDF plots from `utils.tools.visual`.
- `results/<setting>/metrics.npy`, `pred.npy`, `true.npy`: aggregate metric and array outputs.
- `result.txt`: appended text summary lines.
- Optional shell redirection or wrapper logs, usually under `logs/LongForecasting/`.

The setting string is:

```text
{model_id}_{model}_{data}_ft{features}_sl{seq_len}_pl{pred_len}_{des}0
```

Use the wrapper's `--work-dir` to keep smoke or comparison artifacts out of the repository root when desired.

## SARIMA season logic

`SArima` initializes `season = 24`, changes it to `12` only when the case-sensitive substring `Ettm` appears in `data_path`, changes it to `1` when `ILI` appears in `data_path`, and sets it to `1` when `season >= seq_len`. Because common file names such as `ETTm1.csv` do not contain the exact substring `Ettm`, verify this behavior before treating SARIMA numbers as a paper-faithful reproduction.

# Sensors and visualization troubleshooting

## Missing viewer optional dependency

Symptoms:

- `ModuleNotFoundError: pyglet`, `imgui_bundle`, `pxr`, `rerun`, `viser`, or `ovrtx`.
- `ViewerGL`, `ViewerUSD`, `ViewerRerun`, `ViewerViser`, or `ViewerRTX` cannot construct.

Recovery:

- Use `ViewerNull` when no visual output is required.
- Install the smallest extra: `newton[examples]` for GL/example workflows, `newton[rtx]` for RTX, `newton[notebook]` for notebook/Rerun/Viser workflows, or `newton[importers]` for USD support.
- Run `scripts/check_viewer_sensor_apis.py --skip-cli` after installation.

## OpenGL context error on Wayland/Linux

A common symptom is an OpenGL context retrieval error when opening `ViewerGL`.

Recovery:

```bash
export PYOPENGL_PLATFORM=glx
```

Then retry, or use `ViewerNull`, `ViewerUSD`, `ViewerFile`, or a headless path if live OpenGL is not required.

## Rerun or Viser cannot start/connect

Likely causes include missing optional packages, occupied ports, blocked browser/server access, or attempting to start a web viewer in a restricted environment.

Recovery:

- Pass explicit ports or addresses.
- Use recording options instead of a live server when appropriate.
- Fall back to `ViewerFile` or `ViewerUSD` for non-interactive artifact output.
- Do not open network ports or shared sessions without user approval.

## Sensor output arrays are missing

Sensors that need extended attributes request them at construction time. If `State` or `Contacts` was allocated before sensor construction, recreate those buffers after creating the sensor.

For contact sensors, ensure the solver/contact path populates contact forces and that `SensorContact` was created with `request_contact_attributes=True` when needed.

## SensorContact returns zero or stale forces

Check:

1. `CollisionPipeline.collide()` ran for the current state.
2. The solver path updates contact forces before `sensor.update()`.
3. The sensing and counterpart body/shape patterns match labels.
4. Contacts are actually generated by the selected collision route.
5. Contacts were recreated after the sensor requested extended attributes.

Route contact-generation issues to `../solvers-contacts/SKILL.md`.

## Example CLI says unknown example

Run:

```bash
python -m newton.examples --list
```

Example names omit the `example_` prefix and category directory. For example, the module name for a basic pendulum is invoked as `basic_pendulum`.

## Invalid `--warp-config`

`--warp-config` entries must be `KEY=VALUE`, where `KEY` is an existing `warp.config` attribute. Deprecated keys such as `quiet` and `verbose` are rejected; use the example CLI's `--quiet` flag or `log_level` as appropriate.

## Headless run still tries to display

Use `--viewer null` for no visualization. `--headless` only affects viewer backends that support offscreen rendering, such as GL/RTX, and those still need their optional dependencies and platform support.

# Troubleshooting

| Symptom | Likely cause | Safe static check | Typical fix |
| --- | --- | --- | --- |
| `TclError: no display name and no $DISPLAY environment variable` | Tkinter, turtle, customtkinter, or pygame is being launched on a headless host. | Look for `tkinter`, `customtkinter`, `turtle`, `PhotoImage`, `mainloop()`, or `pygame.display.set_mode()`. | Use a real desktop session or keep the task at static inspection only. |
| `pygame.error: No available video device` or mixer/audio init errors | SDL video or audio backend is missing. | Check for `pygame.init()`, `pygame.mixer.init()`, and `pygame.display.set_mode()`. | Run on a machine with display/audio support, or use dummy drivers only for non-interactive checks. |
| `matplotlib` backend errors or a chart window that never appears | The project wants a desktop plotting backend, not just a package import. | Check for `plt_show` signals and `data` tags in the checker output. | Use a real GUI backend or keep the task at static inspection only. |
| `FileNotFoundError` for `images/`, `img/`, `Assets/`, `words.txt`, `dice.png`, `snakeicon.ico`, or `highest_score.txt` | The project assumes the current working directory or a bundled runtime file. | Use the checker output to confirm `asset_dirs`, `asset_files`, and `support_files`. | Run from the project folder or anchor paths to the script directory. |
| Blank icons, broken fonts, or failed image loads | Unsupported formats, wrong case, or missing font/image files. | Check `asset_dirs`, `asset_files`, and any absolute path hints. | Keep the asset next to the code and use the expected format. |
| A window opens but never returns, or the process seems frozen | A top-level `mainloop()`, `while True`, blocking `sleep`, or repeated input loop is active. | Look for `entry_candidates` and loop signals. | Do not launch it unless a live run is explicitly wanted; refactor before trying again. |
| `python-vlc` imports but playback still fails | Native VLC/libvlc is missing or the music folder path is hardcoded. | Check for `vlc` imports and `absolute_paths`. | Install the native VLC runtime and replace hardcoded music locations with a user path. |
| `curses` output is garbled or invisible | The game is not running in a real terminal. | Check for `curses` imports or `curses.wrapper()`. | Use a real TTY, not a notebook, pipe, or redirected log. |
| `requests`, `plotly`, or `pandas` failures in `Chinese_FlashCard` or `Zombie_Game` | The project depends on live web data or a remote source that changed. | Look for `remote_urls`, `network` tags, and data imports. | Treat it as a data dependency, not a GUI bug, if the task is mostly fetching or scraping. |
| README says to `pip install tk`, `pip install random`, or `pip install turtle` | The README is naming stdlib or system modules as if they were pip packages. | Compare the checker output against the external import list. | Ignore that instruction and install only the real external packages. |

# Device Catalog

Use this catalog when selecting Mycodo built-in module families. It is distilled
from module metadata and supported-module documentation. The exact dropdown in a
live Mycodo install can vary by version and installed optional dependencies.

## Source-Inspection Summary

Static inspection of this production snapshot found metadata-bearing module
families in these approximate counts:

| Family | Count | Main runtime use |
|---|---:|---|
| Inputs | 140 | Acquire measurements into InfluxDB |
| Outputs | 46 | Actuate devices by state, duty cycle, volume, or value |
| Functions | 36 | Control, transform, display, compute, or coordinate |
| Actions | 41 | Side effects attached to Inputs, Conditional, and Trigger |
| Widgets | 14 | Dashboard display and manual control |

Many modules declare optional dependencies such as vendor libraries, I2C/GPIO
libraries, MQTT packages, OpenCV, Highcharts files, or hardware-specific system
packages. This production run did not install or exercise those hardware
variants.

## Input Families

### System And Mycodo Inputs

Use these when the measurement is generated by the host, Mycodo itself, or a
command rather than a physical environmental sensor:

- Linux Bash Command and Linux Python 3 Code Inputs.
- Mycodo CPU Load, Free Space, Mycodo Version, System/Mycodo RAM, Uptime, Output
  State, Server Ping, Server Port Open, Test Input, and Spacer.
- Raspberry Pi CPU/GPU Temperature, Edge Detection, GPIO State, Signal PWM, and
  Signal Revolutions.

Configuration risks: command Inputs can execute as privileged code; ping/port
Inputs depend on network timing; GPIO/edge/PWM signal Inputs need correct BCM pin
numbering, debouncing/reset periods, pull-up/down wiring, and hardware support.

### Environmental Sensors

Common choices include:

- Temperature/humidity/pressure: BME280, BME680, BMP180/BMP280, AM2315/AM2320,
  DHT11/DHT20/DHT22, AHTx0, SHT1x/2x/3x/4x/SHTC3, HTU21D, HDC1000, MCP9808,
  Sense HAT, and related CircuitPython variants.
- Light/radiation/color: BH1750, TSL2561, TSL2591, LTR390, AS7262, AS7341,
  VEML7700, Atlas Color.
- Gas/air quality: CCS811, SCD30, SCD-4x, K30, K96, Cozir CO2, MH-Z14A,
  MH-Z16, MH-Z19/MH-Z19B, Winsen ZH03B, Atlas CO2/O2.
- Distance/motion/thermal: HC-SR04, VL53L0X/VL53L1X/VL53L4CD, AMG8833,
  ADXL34x.

Configuration risks: sensor warm-up time, calibration, I2C address conflicts,
UART/FTDI permissions, 1-Wire bus setup, Bluetooth pairing, optional dependency
availability, and Max Age choices.

### Chemistry, Fluid, Power, And Analog Inputs

Use these for dosing, aquaponics, hydroponics, power, weight, and analog signal
workflows:

- Atlas Scientific pH, ORP, EC, DO, Flow, Humidity, Pressure, PT-1000, CO2, O2,
  and Color.
- AnyLeaf pH/ORP/EC.
- Generic analog pH/EC through ADS1115 or ADS1256 variants.
- ADC families: ADS1015, ADS1115, ADS1256, ADS1x15, MCP3008, MCP3208, MCP342x.
- Thermocouple/RTD: MAX31850K, MAX31855 variants, MAX31856, MAX31865 variants.
- Flow/weight/power: Hall Flow Meter, HX711 CircuitPython/RPi.GPIO, INA219x, RPi
  Power Monitor, Kasa Energy Meter, Tasmota Outlet Energy Monitor.

Configuration risks: calibration constants, temperature compensation Max Age,
flow K values, ADC gain/range, probe storage/calibration, current-transformer
range, and pump/chemical safety.

### Network And Remote Inputs

- MQTT Subscribe (JSON payload) and MQTT Subscribe (Value payload).
- The Things Network Data Storage Inputs for TTN v2 and v3, including Payload
  Key and jmespath Expression forms.
- OpenWeatherMap city/current and latitude/longitude current/future.
- Tasmota HTTP energy monitor.
- TP-Link Kasa energy statistics.
- Xiaomi Miflora, Xiaomi Mijia LYWSD03MMC, RuuviTag, Sonoff/Tasmota sensor
  variants.

Configuration risks: credentials, broker/topic shape, payload variable names,
API rate limits, network latency, retained MQTT messages, and stale data.

## Output Families

### On/Off Outputs

Use On/Off Outputs for relays, switches, binary remote commands, and manual
state control:

- Raspberry Pi GPIO for Pi <= 4 and pinctrl-based GPIO for Pi 5.
- Grove Multichannel Relay, SparkFun relay boards, Waveshare relay board,
  Sequent 8-Relay HAT, PiPlates RelayPlate.
- MCP23017, PCF8574, PCF8575, XL9535 I/O expanders.
- Kasa plugs, power strips, and RGB bulbs.
- MQTT Publish, Shell Script, Python Code, Wireless 315/433 MHz.
- Neopixel RGB strip outputs.

Key options: BCM pin, On State, protocol/pulse/bit length for RF, On/Off
commands, Force Command, execute-as user, current draw, startup state, shutdown
state, and Trigger at Startup.

### PWM Outputs

Use PWM Outputs for variable duty cycle control:

- Raspberry Pi GPIO PWM through pigpio or RPi.GPIO variants.
- PCA9685 16-channel LED controller.
- MQTT Publish PWM.
- Shell Script PWM and Python 3 Code PWM.

Key caveats: frequency support differs by library and pin; hardware PWM channels
can be shared by multiple GPIO; non-hardware frequencies are rounded to Mycodo's
supported list; command PWM must include `((duty_cycle))` substitution.

### Volume/Pump Outputs

Use volume Outputs for peristaltic pumps and dosing:

- Generic Raspberry Pi GPIO peristaltic pump.
- Atlas Scientific EZO-PMP.
- Grove I2C Motor Driver board variants.
- L298N DC Motor Controller for Pi <= 4 and Pi 5.
- MCP23017 and PCF8574 expander pump modules.

Key options: Fastest Rate, Flow Rate Method, Desired Flow Rate, Minimum On,
I2C/UART/FTDI details, and safe startup/shutdown behavior.

### Value, DAC, Motor, And Other Outputs

- Value Outputs: MCP4728 DAC, GP8XXX 0-10 VDC DAC, MQTT Value.
- Digital potentiometer: DS3502.
- Stepper motor Outputs: bipolar generic and ULN2003 unipolar.
- Remote Mycodo Output: On/Off and PWM.
- Spacer for layout or grouping.

Value outputs should be bounded by the controlled hardware's voltage/current
range. Stepper/motor outputs need driver wiring, power budget, and movement
safety review before activation.

## Function Families

### Control Functions

- PID Controller: core feedback loop with direction, Period, Max Age, Setpoint,
  Band, Kp/Ki/Kd, integrator limits, output bounds, and Setpoint Tracking.
- PID Autotune: experimental gain estimation by perturbing an Output.
- Bang-Bang Hysteretic On/Off and PWM variants.
- Regulate pH and Electrical Conductivity.
- Conditional Controller and Trigger Controller families are configured from the
  general Function page even though their implementation is core controller
  logic rather than metadata files.

### Computation And Aggregation

- Average, Sum, Statistics over last or past measurements.
- Difference, Equation (single/multi-measure), Vapor Pressure Deficit, Humidity
  Wet/Dry-Bulb.
- Redundancy and Verification helpers.

### Display, Camera, And Operations

- Camera libcamera/rpicam image/video Functions.
- I2C/SPI LCD and OLED display Functions.
- Neokey 4x1 Neopixel keyboard Function.
- Backup to remote host (rsync).
- Spacer and example generic Function.

## Action Families

Actions are added under an Input, Conditional, or Trigger and then run when that
controller executes. Built-ins include:

- **Output Actions**: On/Off/Duration, Duty Cycle, Ramp Duty Cycle, Value,
  Volume.
- **PID Actions**: Setpoint set, raise, lower; Pause; Resume; Set Method.
- **Controller Actions**: Activate and Deactivate controllers.
- **Input Actions**: Force Measurements, Input equation, Input Python code,
  Input MQTT publish.
- **Camera and notification Actions**: Capture Photo, Pause/Resume Time-lapse,
  Send Email, Send Email with Photo, Create Note, Create daemon log line.
- **Messaging/network Actions**: MQTT Publish, MQTT Publish Measurement,
  Webhook.
- **Device Actions**: display backlight/flash controls, LED color/flash controls.
- **Maintenance Actions**: clear total kWh/volume, system restart, system
  shutdown, pause Actions.

Action risks: target ID/channel errors, credentials, command execution,
notification spam, repeated dosing, system restart/shutdown, and hardware state
changes.

## Widget Families

Dashboard Widgets include:

- Activate/Deactivate Controller.
- Camera.
- Function Status.
- Gauge (Angular) and Gauge (Solid) using Highcharts.
- Graph (Synchronous) using Highstock.
- Indicator.
- Measurement (1 Value) and Measurement (2 Values).
- Output Control (Channel).
- Output (PWM Slider).
- PID Controller.
- Python Code.
- Spacer.

Widget caveats: gauges need proper maximum/stop values; Output Control reports
`NO DATA` or `TOO OLD` when Max Age is too short or no recent measurements
exist; Python Code Widgets execute code in the Mycodo context and should be
reviewed like Conditional code.

## Interface And Dependency Hints

Static metadata reported these common interfaces:

- Inputs: I2C, UART, GPIO, FTDI, 1-Wire, Mycodo internal, Bluetooth, SPI, Grove,
  IP, Raspberry Pi, and HTTP.
- Outputs: I2C, GPIO, IP/network, SPI, Python, API/remote, UART, FTDI, and shell.
- General dependencies: many Inputs/Outputs declare optional Python or system
  packages that are installed only when needed by a module.

Treat these as selection hints. A live system still needs OS interface enablement,
permissions, bus addresses, kernel support, and dependency installation.

## Using The Static Catalog Helper

When a checkout is available, run:

```bash
python scripts/summarize_supported_modules.py --repo-root /path/to/Mycodo --family all --limit 40
```

The helper parses metadata dictionaries only. It does not import Mycodo, import
hardware libraries, contact brokers, open serial/I2C/GPIO devices, or execute
module code.

# Workflow map

## Primary routes

| Question | Read |
| --- | --- |
| How do I clean, filter, map, export, or analyze a local dataset? | `sub-skills/recipes-and-ops/SKILL.md` |
| How do I run or recover a Ray-backed job? | `sub-skills/ray-and-recovery/SKILL.md` |
| How do I call Data-Juicer through FastAPI or MCP? | `sub-skills/service-mcp/SKILL.md` |
| Which operators should I use? | `sub-skills/service-mcp/references/operator-discovery.md` and then `sub-skills/recipes-and-ops/SKILL.md` |
| Which dependencies are needed for this workflow? | `references/optional-extras.md` |
| What is the quickest safe environment check? | `scripts/check_environment.py` |

## Routing rule
Start with the root skill when you do not yet know the workflow, then open the matching sub-skill once the task is classified.

# Norfair video visualization workflows

These patterns assume detections or tracked objects already exist. Detector downloads, detector-specific dependencies, tracker distance tuning, initialization delays, and ReID choices belong in `../../tracking-core/SKILL.md`. MOTChallenge evaluation belongs in `../../evaluation/SKILL.md`.

## 1. Video file round-trip with overlays

Use `Video` when you want a simple OpenCV frame loop that reads a file and writes an annotated output.

```python
import numpy as np
from norfair import Detection, Video
from norfair.drawing import Color, Palette, draw_boxes, draw_points

Palette.set("colorblind")
video = Video(input_path="input.mp4", output_path="runs/overlay.mp4")

for frame in video:
    # Example detector output already converted to Norfair-style points.
    point_detection = Detection(
        points=np.array([[80, 60]], dtype=float),
        scores=np.array([0.92]),
        label="centroid",
    )
    box_detection = Detection(
        points=np.array([[40, 30], [120, 90]], dtype=float),
        scores=np.array([0.88, 0.88]),
        label="box",
    )

    draw_points(
        frame,
        [point_detection],
        color="by_label",
        draw_labels=True,
        draw_scores=True,
        draw_ids=False,
        text_color=Color.white,
    )
    draw_boxes(
        frame,
        [box_detection],
        color=Color.orange,
        draw_labels=True,
        draw_scores=True,
        draw_ids=False,
    )
    video.write(frame)
```

Notes:

- `Video.write(frame)` opens the output writer on the first call and uses that frame's size.
- Use `output_path="folder"` plus `output_extension="mp4"` if you want Norfair to generate `<input>_out.mp4`.
- Prefer writing video in headless environments; `Video.show(...)` requires an OpenCV GUI display.

## 2. Camera input loop

Use `camera=<int>` for a live feed. Provide `output_fps` for cameras when the source FPS is unavailable or detector latency reduces processing speed.

```python
from norfair import Video

video = Video(camera=0, output_path="camera_debug.mp4", output_fps=30)
for frame in video:
    # draw overlays here
    video.write(frame)
```

Do not pass both `camera` and `input_path`. If the camera route creates surprising autogenerated names, set `output_path` to a full file path.

## 3. Point versus box drawing

Choose the drawer by the coordinate representation, not by the detector family.

| Detection shape | Best drawer | Example |
| --- | --- | --- |
| One centroid point `[[cx, cy]]` | `draw_points` | object center tracking, dots, landmarks when each point matters. |
| Multiple keypoints `[[x1, y1], ...]` | `draw_points` | pose/keypoint visualization; dead tracked points can be hidden. |
| Two box corners `[[x0, y0], [x1, y1]]` | `draw_boxes` | bounding-box detections or tracked boxes. |

Legacy examples may use `draw_tracked_objects` or `draw_tracked_boxes`. Treat those as compatibility wrappers and translate new code to `draw_points` / `draw_boxes`.

## 4. Relative path trails on a static camera

Use `Paths` when the frame coordinate system is stable. It keeps an internal mask, so create one drawer and reuse it across frames.

```python
from norfair.drawing import Paths, draw_boxes

path_drawer = Paths(attenuation=0.02)  # 0 keeps paths forever

for frame in video:
    tracked_objects = tracker.update(detections=detections)
    draw_boxes(frame, tracked_objects, draw_labels=True)
    frame = path_drawer.draw(frame, tracked_objects)
    video.write(frame)
```

If `tracked_objects` came from a tracker that received camera-motion coordinate transformations, switch to `AbsolutePaths`; `Paths` records relative frame positions and will not give a stable world trajectory.

## 5. Frame-folder / MOT-style video construction

Use `VideoFromFrames` only when the input folder has a `seqinfo.ini` with MOT-style fields.

```python
from norfair.video import VideoFromFrames

sequence = VideoFromFrames("sequence_dir", save_path="runs")
for frame in sequence:
    if frame is None:
        raise RuntimeError("Missing or unreadable frame in sequence_dir")
    # draw overlays here
    sequence.update(frame)
```

Expected file layout:

```text
sequence_dir/
  seqinfo.ini         # frameRate, imWidth, imHeight, seqLength, imExt, imDir
  img1/
    000001.jpg
    000002.jpg
```

The output video is written under `runs/videos/<sequence_dir_name>.mp4`.

## 6. Moving-camera motion estimation loop

Use `MotionEstimator` before drawing overlays. If a detector/tracker is in the loop, pass the returned coordinate transformation to the tracker update, but keep tracker parameter choices in `tracking-core`.

```python
import numpy as np
from norfair.camera_motion import (
    MotionEstimator,
    TranslationTransformation,
    TranslationTransformationGetter,
)
from norfair.drawing import AbsolutePaths, FixedCamera, draw_absolute_grid, draw_boxes

motion_estimator = MotionEstimator(
    transformations_getter=TranslationTransformationGetter(),
    draw_flow=False,
)
identity = TranslationTransformation(np.zeros(2))
coord_transform = identity
absolute_paths = AbsolutePaths(max_history=80, thickness=2)
fixed_camera = FixedCamera(scale=2.0)

for frame in video:
    mask = np.ones(frame.shape[:2], dtype=frame.dtype)
    # If detector boxes are available, set their regions to 0 before motion estimation.
    # for box in detector_boxes_xyxy:
    #     x0, y0, x1, y1 = box.astype(int)
    #     mask[y0:y1, x0:x1] = 0

    estimated = motion_estimator.update(frame, mask=mask)
    if estimated is not None:
        coord_transform = estimated

    tracked_objects = tracker.update(
        detections=detections,
        coord_transformations=coord_transform,
    )

    draw_boxes(frame, tracked_objects, draw_labels=True)
    draw_absolute_grid(frame, coord_transform, grid_size=16)
    frame = absolute_paths.draw(frame, tracked_objects, coord_transform=coord_transform)

    # FixedCamera must be the last renderer and only works with translation transforms.
    stabilized = fixed_camera.adjust_frame(frame, coord_transform)
    video.write(stabilized)
```

Translation versus homography:

- Use `TranslationTransformationGetter` for pan/tilt-like shifts and whenever you need `FixedCamera` stabilization.
- Use `HomographyTransformationGetter` for rotation, zoom, or general projective movement. Skip `FixedCamera` in that mode; use `draw_absolute_grid` and `AbsolutePaths` for inspection instead.
- If `MotionEstimator.update(...)` returns `None`, keep the last good transform or use identity on the first frame. Do not pass `None` to `FixedCamera.adjust_frame(...)`.

## 7. Inspect camera motion with a grid and optical flow

For debugging, turn on optical-flow drawing or add an absolute grid:

```python
from norfair.camera_motion import HomographyTransformationGetter, MotionEstimator
from norfair.drawing import Color, draw_absolute_grid

motion_estimator = MotionEstimator(
    max_points=800,
    min_distance=10,
    transformations_getter=HomographyTransformationGetter(),
    draw_flow=True,
)

for frame in video:
    coord_transform = motion_estimator.update(frame)
    draw_absolute_grid(
        frame,
        coord_transform,
        grid_size=20,
        radius=2,
        thickness=1,
        color=Color.cyan,
    )
    video.write(frame)
```

Grid drift usually means the transform is not estimating the background. Mask moving objects, avoid drawing overlays before motion estimation, increase textured background coverage, or switch between translation and homography based on the real camera motion.

## Safe bundled helpers

Run the helpers from this sub-skill directory:

```bash
python scripts/video_smoke.py --output-dir ./norfair-video-smoke
python scripts/camera_motion_smoke.py --output-dir ./norfair-camera-motion-smoke
```

The first helper generates a tiny local video, overlays point/box detections and a path, writes it with `Video`, and re-reads the output. The second helper generates a synthetic translated scene, estimates camera motion without detectors, draws an absolute grid/path, stabilizes the frame, and verifies that an output video is readable.

# License and Safety Notes

The repository code is Apache-2.0 according to the README, while the
ChatGLM2-6B model weights have a separate model license. The weight license
requires its notice to accompany copies/substantial portions and prohibits
military or illegal use, use that harms national security or public interests,
and infringement of human rights. It also provides the weights as-is without
warranty.

Before distributing weights, checkpoints, containers, or a public service,
review the current `MODEL_LICENSE` and any updated terms from the model team.
Do not assume that an Apache-2.0 code license grants unrestricted rights to
model parameters. Do not expose an unauthenticated sample API to untrusted
traffic; add access controls, data handling, and safety evaluation appropriate
to the application.

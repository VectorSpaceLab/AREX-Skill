# Troubleshooting pgmpy extension work

| Symptom or request | Likely cause | Action |
|---|---|---|
| User asks to add a new discovery algorithm, CI test, score, or parameter-learning feature under `pgmpy.estimators`. | `pgmpy.estimators` is a legacy compatibility layer. New structure learning belongs in `pgmpy.causal_discovery`, scores in `pgmpy.structure_score`, CI tests in `pgmpy.ci_tests`, and parameter learning in `pgmpy.parameter_estimator`. | Reroute the implementation to the canonical package. Add a legacy shim only if maintainers require backwards compatibility, and test both paths. |
| `get_ci_test("new_name", data=...)` cannot find the test. | Missing or misspelled `_tags["name"]`, package `__init__.py` export, class not subclassing `BaseCITest`, or installed package not refreshed. | Verify the class inherits `BaseCITest`, `_tags` includes the lower-case lookup name, `pgmpy/ci_tests/__init__.py` imports it and lists it in `__all__`, then rerun the focused test from a fresh Python process. |
| New CI test returns booleans directly from `_compute_result`. | `BaseCITest` expects `_compute_result` to return `_CITestResult`; booleans are returned by `is_independent` after comparing `p_value_` with `significance_level`. | Return `_CITestResult(statistic=..., p_value=..., effect_size=..., attributes={...})`. Put derived attributes in `attributes` so the base class projects them after cache lookup. |
| `get_scoring_method("new-score", data)` cannot find the score. | Missing `_tags["name"]`, missing `__init__.py` export/`__all__`, filename begins with `_`, or tag spelling drifts from current concrete scores. | Use a non-underscore module filename, subclass `BaseStructureScore` or a compatible existing score, add import/`__all__`, and align tag keys with current source. In this version, existing scores use `is_parameteric`. |
| A score gives inconsistent repeated local scores. | `_local_score` has side effects or receives unhashable/non-canonical parent collections. | Keep `_local_score(variable, parents)` deterministic and treat `parents` as a tuple. Public `local_score` handles caching; tests should call the same local score twice. |
| `get_metrics(...)` returns no class for a new metric. | Missing required metric tags, wrong base class, or missing public export. | Choose `BaseSupervisedMetric` for graph-vs-graph or `BaseUnsupervisedMetric` for data-vs-graph, define required tags, implement `_evaluate`, export in `pgmpy/metrics/__init__.py`, and test `get_metrics(name="...")`. |
| Metric raises graph/data validation errors unexpectedly. | Declared `supported_graph_types` do not match actual inputs, graph nodes differ, or data is missing graph columns. | Decide supported graph families deliberately (`DAG`, `PDAG`, etc.), add tests for node mismatch and missing data columns, and document whether lower or higher values are better. |
| `list_datasets()` or `load_dataset()` does not include a new dataset. | Tag name missing/duplicated, class not discoverable in `pgmpy/datasets`, test list not updated, or loader overridden incorrectly. | Set unique `_tags["name"]`, avoid leading-underscore modules for public datasets, update dataset tests, and verify `load_dataframe`, `load_ground_truth`, and `load_expert_knowledge` behavior with a tiny deterministic check. |
| Dataset tests hang or fail due network. | Dataset loader depends on remote Hub access and no local cache/network is available. | Keep remote access explicit. Use small cached fixtures or guarded/marked tests where appropriate, and do not make core extension tests require optional network access. |
| `list_models()` or `load_model()` misses a new example model. | Wrong source subpackage, missing `__init__.py` in a new source namespace, malformed `name` tag, or wrong mixin. | Place under `pgmpy/example_models/<source>/`, create `__init__.py` for new source, set `name` as `source/model`, choose the correct mixin, and update example-model tests. |
| Continuous example model JSON fails validation or loading. | The LGBN JSON schema is violated. | Ensure top-level `nodes`, `arcs`, and `cpds` exist; arcs are source/target pairs; every CPD has `coefficients` containing `"(Intercept)"`, positive one-element `variance`, and a `parents` list. Run the LGBN schema test when adding/changing these assets. |
| New causal discovery estimator fails sklearn-style checks or score calls. | `_fit` does not set `causal_graph_`, feature metadata, or a compatible graph type; `fit` signature drifts; progress/randomness is not controlled. | Inherit `BaseCausalDiscovery`, implement `_fit`, set `causal_graph_` and `adjacency_matrix_`, use deterministic seeds or fixtures in tests, and check `score(X=..., metric=...)` or `score(true_graph=...)` when applicable. |
| Base-class API changed but templates still show old TODOs/signatures. | Template sync was skipped. | Update the corresponding file under `devtools/extension_templates/`, adjust docs if needed, and add/modify a focused test that would fail if future templates drift again. |
| Imports fail for torch/Pyro, litellm, plotting, or provider credentials. | Optional extras were not installed in the minimum environment. | Do not import optional dependencies at module import time. Use local guarded imports, `pytest.importorskip`, environment/credential skips, and document the optional extra (`torch`, `optional`, plotting/system graphviz, provider network) only where needed. |
| Focused pytest command is too broad or slow. | Running the entire suite before narrowing the failure. | Start with the new test file or a selected existing method/class. Broaden to the relevant family, then full `pytest -v pgmpy` only if the change affects multiple packages. |
| Pre-commit is unavailable. | The minimum environment may not include dev tooling. | State that pre-commit is unavailable, run the smallest available `ruff`/format/pytest checks, and leave final pre-commit to the reviewer or a prepared dev environment. |
| User asks to run `devtools/scripts/convert_bnrep_models.R` for a normal extension. | That script is an R/external-context maintainer conversion helper, not a public Python extension workflow. | Treat it as reference-only. Only use it when the task explicitly concerns maintainer bnRep conversion and the user accepts the R package/network requirements. |

# Repo-Level Embeddings Summary

For detailed instructions, use `sub-skills/integrations-and-extensions/references/embeddings.md`.

Install an embeddings extra only when semantic search is required. Local sentence-transformers embeddings are optional. OpenAI-compatible, Google, MiniMax, and Voyage providers require explicit provider configuration and may send code-derived text to external services, so stop for user approval when privacy or credentials are unclear.

# Training and Checkpointing Troubleshooting

Use this matrix for common `ImagenTrainer`, dataloader, checkpoint, and Accelerate failures.

| Symptom / message | Likely cause | Recovery |
| --- | --- | --- |
| `ImagenTrainer can only be initialized once per process` | A distributed process already created a trainer; the class lock prevents multiple trainers for safe distributed training. | Use one trainer per script/process and relaunch for another unet. Only local smoke scripts may reset `ImagenTrainer.locked = False` between sequential toy trainers. |
| `either imagen instance is passed into the trainer, or a checkpoint path...` | Neither or both `imagen` and `imagen_checkpoint_path` were supplied. | Supply a concrete `Imagen`/`ElucidatedImagen` instance. In 2.1.0, do not rely on `imagen_checkpoint_path` alone; use `load_imagen_from_checkpoint` or reconstruct then `trainer.load`. |
| Assertion after using only `imagen_checkpoint_path` | The signature exposes the argument, but the implementation still immediately checks that `imagen` is an actual model. | Load/create the model first, then pass `imagen=...` to `ImagenTrainer`. |
| `either set fp16 = True or forward the precision...` | Both `fp16=True` and `precision` were set. | Choose one: `fp16=True` or `precision="fp16"` / `"bf16"` / `"no"`. |
| `training dataloader was already added` or `validation dataloader was already added` | Attempted to register a duplicate loader/dataset. | Create a fresh trainer for a new dataset, or register exactly once before training. |
| `You need to add the dataset before preperation` | Tried to add a dataloader after `prepare()` was triggered by `train_step`, `valid_step`, or manual preparation. | Reorder setup: instantiate trainer, add train/valid data, then train/validate. If already prepared, recreate the trainer. |
| `training dataloader has not been registered with the trainer yet` | Called `train_step` before `add_train_dataset` or `add_train_dataloader`. | Add a training dataset/dataloader first. For manual tensor batches, call `trainer(...)` followed by `trainer.update(...)` instead of `train_step`. |
| `validation dataloader has not been registered...` | Called `valid_step` without a validation loader. | Register `add_valid_dataset` / `add_valid_dataloader`, or set `split_valid_from_train=True` before `add_train_dataset`. |
| Dataloader batch produces missing or wrong arguments | Default tuple order maps to `images`, `text_embeds`, `text_masks`, `cond_images`. | Return the correct tuple or set `dl_tuple_output_keywords_names`. Route schema validation to [data-and-text-conditioning](../../data-and-text-conditioning/SKILL.md). |
| `unet number should be in between 1 and N` | Missing/invalid one-based unet index for multi-unet model. | Pass `unet_number=1..N`. Single-unet trainers can omit it. |
| `you cannot only train on one unet at a time` or `you can only train unet #...` | The trainer was pinned to another `only_train_unet_number`, or a different unet was already selected. | Save, start a fresh process/trainer, load the checkpoint, then train the next unet. |
| OOM during training despite small dataloader | Effective batch still too large for model/resolution, or all unets/EMA/sample state are on device. | Lower dataloader `batch_size`, set smaller `max_batch_size`, reduce resolution/model dimensions, sample less often, or use practical CUDA resources. Tiny CPU smoke is not evidence of real training feasibility. |
| `split_args_and_kwargs` assertion or no batch-size inference | Manual `trainer(...)` call did not include any tensor inputs. | Include `images` and, for text-conditioned models, `text_embeds` or text inputs. For text strings and T5 implications, route to data/text conditioning guidance. |
| `checkpoint_path` / `checkpoint_every` assertion | Only one of the two folder-checkpoint arguments was supplied. | Set both for managed folders or neither for manual `save()` / `load()`. |
| Save assertion with existing file | `save(..., overwrite=False)` found an existing target. | Choose a new path or intentionally allow overwrite. |
| Checkpoint lacks `imagen_type` / `imagen_params`; CLI sample cannot load | Model was not created through `ImagenConfig` or `ElucidatedImagenConfig`, or checkpoint was not saved by `trainer.save`. | Recreate/save through config classes for commandable checkpoints. Otherwise reconstruct architecture in code and call `trainer.load`. |
| Version mismatch warning on load | Checkpoint package version differs from current package. | Prefer the same package version. If continuing, run a tiny load/train smoke and inspect partial-load messages. |
| `Failed loading state dict. Trying partial load` | Architecture changed or state shapes differ. | Treat as partial restore. Verify skipped/mismatched layers and do not claim full resume unless intended. |
| `could not load optimizer and scaler...` | Mixed precision or optimizer/scaler setup changed since checkpoint. | Continue as fine-tune with fresh optimizer/scaler state, or match precision/optimizer settings and reload. |
| `assert 'ema' in loaded_obj` | Current trainer uses EMA but checkpoint lacks EMA state. | Instantiate with `use_ema=False`, or load model weights only and rebuild EMA from fresh training. |
| fsspec/cloud path fails before training | URL-style checkpoint path or credentials are unsupported/untested. | Use local paths, test a tiny save/load, pass a verified `checkpoint_fs`, or stage locally then upload separately. |
| Accelerate run prints/saves from every process | Side effects were not guarded. | Use `trainer.is_main` for global logging/sample/save and let trainer folder checkpointing handle process gating. |
| Accelerate launch hangs or behaves like single process | Training script was run with `python` instead of `accelerate launch`, or `accelerate config` is missing/mismatched. | Run `accelerate config`, then `accelerate launch train.py --unet N`. Keep script arguments deterministic across processes. |
| Sampling warns untrained unets | Later cascade unets have zero steps and are not `NullUnet`. | Train all non-null stages before full sampling, or pass `stop_at_unet_number` for partial previews. |

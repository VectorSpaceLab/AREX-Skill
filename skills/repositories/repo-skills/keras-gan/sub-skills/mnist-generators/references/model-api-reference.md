# MNIST-Generator Model API Reference

This reference condenses the standalone Keras-GAN scripts that do not require paired image-domain directories. It is intended to be sufficient for future agents to select, inspect, adapt, or troubleshoot these models without reopening the source checkout.

## Common conventions

- Runtime family verified for representative imports/constructors: Python 3.7-era, TensorFlow 1.15.x, Keras 2.2.x, NumPy 1.18.x, SciPy 1.2.x, Matplotlib, Pillow, and scikit-image. Do not use latest standalone Keras for these scripts without porting.
- All covered scripts are standalone files rather than an installable Python package. Import them by file path or by running from their script directory.
- All covered training loops load Keras MNIST via `keras.datasets.mnist.load_data()` except adaptations a user may make. CoGAN and DualGAN create a second domain by rotating half of MNIST with SciPy; they still do not require image-domain folders.
- Image-valued MNIST models scale pixels to `[-1, 1]` and usually expand grayscale arrays to `(N, 28, 28, 1)`. DualGAN flattens images to length `784`.
- Sample image methods rescale generated outputs back to `[0, 1]` and save PNG grids under `images/` relative to the process working directory.
- The README examples run each script directly from its own directory, but the `__main__` calls use thousands of epochs and are not safe smoke defaults.

| `acgan/acgan.py` | `ACGAN` | MNIST labels, `num_classes=10`, `img_shape=(28, 28, 1)`, `latent_dim=100`; generator conditioned by label embedding; discriminator emits validity plus class label. | `ACGAN()` builds `generator`, `discriminator`, `combined`; `train(epochs, batch_size=128, sample_interval=50)`; `save_model()`. | Loss list `['binary_crossentropy', 'sparse_categorical_crossentropy']`; `Adam(0.0002, 0.5)`. | `ACGAN().train(epochs=14000, batch_size=32, sample_interval=200)`; every sample interval calls `save_model()` then `sample_images(epoch)`, writing `saved_model/generator*.hdf5/json`, `saved_model/discriminator*.hdf5/json`, and `images/%d.png`. |
| `sgan/sgan.py` | `SGAN` | MNIST labels, `num_classes=10`, fake class index `10`, `img_shape=(28, 28, 1)`, `latent_dim=100`; discriminator has validity and 11-class output. | `SGAN()` builds `generator`, `discriminator`, `combined`; `train(epochs, batch_size=128, sample_interval=50)`; `save_model()` available but not called by `train`. | Discriminator losses `['binary_crossentropy', 'categorical_crossentropy']` with `loss_weights=[0.5, 0.5]`; combined uses `['binary_crossentropy']`; `Adam(0.0002, 0.5)`. | `SGAN().train(epochs=20000, batch_size=32, sample_interval=50)`; `sample_images(epoch)` writes `images/mnist_%d.png`; optional `save_model()` writes `saved_model/mnist_sgan_*`. |
| `infogan/infogan.py` | `INFOGAN` | MNIST labels, `num_classes=10`, `img_shape=(28, 28, 1)`, `latent_dim=72`; generator input concatenates 62 Gaussian noise values and 10 categorical-code values. | `INFOGAN()` builds `generator`, `discriminator`, `auxilliary` Q-network, and `combined`; `train(epochs, batch_size=128, sample_interval=50)`; `sample_generator_input(batch_size)`; `save_model()`. | Discriminator uses `binary_crossentropy`; auxiliary and combined use `mutual_info_loss` for categorical code; `Adam(0.0002, 0.5)`. | `INFOGAN().train(epochs=50000, batch_size=128, sample_interval=50)`; `sample_images(epoch)` writes `images/%d.png`; optional `save_model()` writes `saved_model/generator*` and `saved_model/discriminator*`. |
| `lsgan/lsgan.py` | `LSGAN` | MNIST grayscale, `img_shape=(28, 28, 1)`, `latent_dim=100`; MLP generator/discriminator like vanilla GAN. | `LSGAN()` builds `generator`, `discriminator`, `combined`; `train(epochs, batch_size=128, sample_interval=50)`. | Discriminator and combined use least-squares `mse`; `Adam(0.0002, 0.5)`. | `LSGAN().train(epochs=30000, batch_size=32, sample_interval=200)`; `sample_images(epoch)` writes `images/mnist_%d.png`. |

| `bigan/bigan.py` | `BIGAN` | MNIST grayscale, `img_shape=(28, 28, 1)`, `latent_dim=100`; encoder maps images to latent, generator maps latent to images, discriminator receives `[z, img]`. | `BIGAN()` builds `encoder`, `generator`, `discriminator`, and `bigan_generator`; `train(epochs, batch_size=128, sample_interval=50)`; output method is named `sample_interval(epoch)`. | Discriminator uses `['binary_crossentropy']`; `bigan_generator` uses two `binary_crossentropy` losses; `Adam(0.0002, 0.5)`. | `BIGAN().train(epochs=40000, batch_size=32, sample_interval=400)`; `sample_interval(epoch)` writes `images/mnist_%d.png`. |

| `wgan/wgan.py` | `WGAN` | MNIST grayscale, `img_shape=(28, 28, 1)`, `latent_dim=100`; DCGAN-like generator and critic. | `WGAN()` builds `generator`, `critic`, and `combined`; `wasserstein_loss`; `train(epochs, batch_size=128, sample_interval=50)`. | Critic and combined use `wasserstein_loss`; labels use valid `-1` and fake `+1`; `RMSprop(lr=0.00005)`; `n_critic=5`; `clip_value=0.01`. | `WGAN().train(epochs=4000, batch_size=32, sample_interval=50)`; `sample_images(epoch)` writes `images/mnist_%d.png`. |
| `wgan_gp/wgan_gp.py` | `RandomWeightedAverage`, `WGANGP` | MNIST grayscale, `img_shape=(28, 28, 1)`, `latent_dim=100`; DCGAN-like generator/critic with gradient penalty. | `WGANGP()` builds `generator`, `critic`, `critic_model`, and `generator_model`; `gradient_penalty_loss(y_true, y_pred, averaged_samples)`; `wasserstein_loss`; `train(epochs, batch_size, sample_interval=50)` where `batch_size` has no default. | Critic model losses `[wasserstein_loss, wasserstein_loss, gradient_penalty]` with `loss_weights=[1, 1, 10]`; generator model uses `wasserstein_loss`; labels use valid `-1`, fake `+1`, dummy zeros; `RMSprop(lr=0.00005)`; `n_critic=5`. | `WGANGP().train(epochs=30000, batch_size=32, sample_interval=100)`; `sample_images(epoch)` writes `images/mnist_%d.png`; `RandomWeightedAverage._merge_function` uses fixed `alpha` shape `(32,1,1,1)`. |

## Special methods and pitfalls

| Method | Where | Purpose | Adaptation notes |
|---|---|---|---|
| `wasserstein_loss(y_true, y_pred)` | `WGAN`, `WGANGP`, `DUALGAN` | Implements `K.mean(y_true * y_pred)` for Wasserstein-style critics. | Preserve label convention: valid is `-1`, fake is `+1` in these scripts. Changing signs changes printed loss interpretation. |
| `gradient_penalty_loss(y_true, y_pred, averaged_samples)` | `WGANGP` | Computes squared penalty on `1 - ||grad||` for critic predictions on interpolated real/fake samples. | Requires a graph backend with `K.gradients`; modern eager TensorFlow/Keras ports need a rewrite. The script binds `averaged_samples` via `functools.partial`. |
| `RandomWeightedAverage._merge_function(inputs)` | `wgan_gp/wgan_gp.py` | Produces interpolated samples for gradient penalty using legacy `_Merge`. | The fixed `alpha` shape assumes batch size 32; for other batch sizes, patch `alpha` to use `K.shape(inputs[0])[0]`. |
| `boundary_loss(y_true, y_pred)` | `BGAN` | Boundary-seeking generator objective `0.5 * mean((log(D) - log(1-D))**2)`. | Can become numerically unstable when predictions are exactly 0 or 1; clipping or epsilon protection is needed in modern robust ports. |
| `mutual_info_loss(c, c_given_x)` | `INFOGAN` | Mutual-information-inspired categorical-code loss used by the auxiliary Q-network. | The implementation returns conditional entropy plus entropy as written; preserve `to_categorical` code shape `(batch, 10)`. |
| `sample_generator_input(batch_size)` | `INFOGAN`, `DUALGAN` | InfoGAN samples `(noise_62, one_hot_labels)`; DualGAN samples a batch from a provided domain matrix. | InfoGAN concatenates to latent input length 72; DualGAN expects flattened domain arrays. |
| `save_model()` | `ACGAN`, `SGAN`, `INFOGAN`, `AdversarialAutoencoder` | Serializes model JSON and HDF5 weights under `saved_model/`. | Create `saved_model/` first. AAE's method references `self.generator` even though the class defines `self.decoder`; patch before calling. |

## Selection guidance

- Use `GAN` or `LSGAN` for smallest MLP examples where architecture complexity should stay low.
- Use `DCGAN`, `WGAN`, or `WGANGP` when convolutional generator/critic behavior matters. Prefer `WGAN` over `WGANGP` if the runtime cannot support legacy `_Merge`.
- Use `CGAN` or `ACGAN` for label-conditioned image generation. `ACGAN` trains an auxiliary classifier and writes saved models during sample intervals.
- Use `SGAN` when the discriminator should model real digit labels plus a fake class.
- Use `INFOGAN` when the workflow needs categorical latent-code inspection through a Q-network.
- Use `BIGAN` or `AdversarialAutoencoder` when an encoder/latent representation is central.
- Use `COGAN` or `DUALGAN` only for synthetic two-domain MNIST experiments that do not require image folders; route real image-domain translation to the image-translation sub-skill.

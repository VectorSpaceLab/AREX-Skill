# Maps and visualization troubleshooting

| Symptom | Likely cause | Recovery / validation |
|---|---|---|
| `import sunpy.map` warns about missing dependencies or fails on WCS plotting | `map`, image, visualization, Matplotlib, or Astropy WCSAxes dependency is absent/incompatible | Use an isolated Python >=3.12 environment and install the map/image/visualization extras appropriate to the workflow. Probe `import sunpy.map`, `import matplotlib`, and `import astropy.wcs`; do not claim plotting/reprojection from a base import alone. |
| `reproject_to()` raises `ImportError` | `reproject` extra is missing | Install/enable the map/reproject optional dependency or route alignment elsewhere. A resize/resample is not WCS reprojection. Re-run a tiny target-WCS smoke check. |
| `rotate(method='scikit-image')` or `method='opencv'` is rejected/imports fail | Optional rotation implementation is not installed or method name is unsupported | Use the verified default `method='scipy'`, or install the selected optional extra. Check supported methods and expected interpolation order. |
| ASDF load/save fails | ASDF extra/entry points are missing, or the file is not an ASDF map | Check `import asdf`, use a `.asdf` suffix with `filetype='auto'`, and fall back to FITS. Do not assume source-specific subclass restoration; validate type and metadata after reload. |
| JP2 read/write fails or values change | JPEG2000 codec/extra is unavailable; JP2 output is uint8-oriented | Install the JP2 extra only when needed. Use FITS/ASDF for scientific values and metadata. Treat JP2 as an optional interchange/quicklook format. |
| `Map(data)` says an array must be followed by a header | Factory cannot infer WCS from an array alone | Call `Map(data, header)` or `Map((data, header))`, where header is a dict/MetaDict/FITS Header/WCS. Use `make_fitswcs_header()` for synthetic data. |
| `Map(data, 42)` or `Map(78)` raises invalid input | Factory dispatch is type-sensitive | Pass a 2-D array plus header/WCS, a local path, or an existing GenericMap. A NumPy array of filenames is not the same as a Python list. |
| `Map` returns a list unexpectedly | Multiple files/HDU pairs were found and no container flag was requested | Inspect each map, or request `sequence=True` / `composite=True` according to intent. For a sequence, maps must be already valid and are sorted by date by default. |
| `Map(..., allow_errors=True)` returns no maps | Every candidate failed validation/read | Treat as failure; inspect warnings and retry without `allow_errors` on one local input to expose the root exception. Do not silently proceed with an empty collection. |
| `MapMetaValidationError: Image coordinate units ... not present` | `CUNIT1`/`CUNIT2` missing | Repair a copied header with evidence-backed angular units, reconstruct, and validate frame/WCS. Never guess units from array size or a plot. |
| `MapMetaValidationError` says units are not angular | Header describes unsupported physical/linear axes | Use a correct solar spherical WCS or a different data model; do not force `arcsec` merely to pass validation. |
| Map constructs but `.coordinate_frame` is `None` or warnings mention missing CTYPE | CTYPE or related WCS metadata is missing/malformed | Inspect `m.meta` and `m.wcs`; repair CTYPE and related keys from authoritative metadata. Restrict use to data inspection until frame inference succeeds. |
| `make_fitswcs_header()` rejects coordinate | Not a SkyCoord/frame, missing `obstime`, or heliocentric coordinate | Pass a valid SkyCoord/SunPy frame with observation time. Use helioprojective/heliographic frame appropriate to the projection; route frame construction/theory to coordinates-and-time. |
| `make_fitswcs_header()` rejects both rotation arguments | `rotation_angle` and `rotation_matrix` are mutually exclusive | Supply exactly one, or neither for an identity rotation. Validate the resulting PC matrix. |
| Header's CRPIX is off by one | Mixed zero-based Python and one-based FITS conventions | Public `reference_pixel` is zero-indexed Cartesian `(x, y)`; FITS CRPIX is generated as reference + 1. Do not manually add one twice. |
| Pixel/world round trip is wrong or overlay is displaced | Coordinate frame/observer/time mismatch, x/y vs y/x confusion, or plotting on a different WCS | Use `m.coordinate_frame` for test coordinates, use `(x, y)` public pixel order, verify `.wcs`, and plot on `projection=m`. Transform coordinates deliberately before overlay. |
| `submap` has unexpected size or fails | Pixel coordinates were given in NumPy order, or both/none of top-right and width/height were supplied | Use bottom-left/top-right in Cartesian `(x, y)`; supply `top_right` or both `width` and `height`. Pixels intersecting the region can be included. |
| `resample`/`rotate` changes data shape or WCS scale unexpectedly | These operations intentionally derive new shape/scale/reference metadata | Assert the requested output shape and inspect new `.scale`, `.reference_pixel`, and `.wcs`. Keep the source map for comparison. `spline` plus NaN/Inf can produce all-NaN output. |
| `reproject_to` raises invalid algorithm/extent | Algorithm is not `interpolation`, `adaptive`, or `exact`; extent is not `None`, `corners`, `edges`, or `all` | Correct the keyword and start with `interpolation`, `auto_extent=None`. Verify target WCS shape and inspect footprint. |
| Reprojection warns about `rsun mismatch` | Source and target solar-radius metadata disagree | Investigate physical metadata and choose a consistent target. Do not suppress the warning for scientific interpretation. |
| `preserve_date_obs=True` raises about target date | Target WCS lacks `DATE-AVG` and `DATE-OBS` | Add a defensible target reference date or leave preservation disabled and document date semantics. |
| Reprojection is slow, memory-heavy, or output mostly empty | Large arrays, `exact`/`adaptive`, broad `auto_extent='all'`, or incompatible WCS/observers | Test with a tiny map, use interpolation, set explicit `shape_out`/target shape, inspect footprint, and use `corners`/`edges` only when their coverage trade-off is acceptable. |
| `plot()` raises about axes not being WCSAxes | A normal Matplotlib axis was supplied | Create it with `fig.add_subplot(projection=m)` or omit `axes` and let SunPy obtain a WCS axis. |
| Overlay is visibly misaligned and a warning says WCS differs | Map and axes have different WCS | Reproject the overlay to `axes.wcs`, or use `autoalign=True` knowingly and validate its output. Do not merely silence the warning. |
| `peek()` opens a browser/window or hangs in CI | Convenience quicklook is interactive | Use `MPLBACKEND=Agg`, `plot`, and `fig.savefig()`; avoid `peek`/`quicklook` in automated checks. |
| `draw_grid` does not behave like `ax.grid` | SunPy grid and WCSAxes coordinate grids are distinct | Use `m.draw_grid(system=...)` for heliographic overlays; use `ax.coords[i].grid(...)` to control WCSAxes grid lines. |
| `draw_limb`/`draw_grid` fails on a synthetic or non-observer map | Required observer/solar geometry is absent or unsuitable | Use a map made with a valid observer/time, or restrict to WCS image plotting and document the unavailable overlay. |
| `MapSequence.data` raises because shapes differ | Sequence members are not same shape | Use individual maps or crop/reproject to a common WCS/shape first. A sequence does not coalign automatically. |
| Figure is blank, saturated, or dominated by outliers | Default normalization/data range is unsuitable | Use `clip_interval=(low, high)*u.percent`, a deliberate `norm`, and a colormap suited to the measurement. Check finite values and scientific units before clipping. |
| FITS round-trip loses expected values/keys | Unrepresentable metadata, chosen HDU/filetype, or format conversion | Compare WCS keys and data after reload, save to a new file, and use ASDF when richer SunPy metadata/masks are needed. |

## Explicit exclusions

- Remote URLs, Fido search/fetch, sample-data downloads, and mission-scale files belong to data-access-and-io and are not bundled into smoke scripts.
- GUI point selection, browser quicklooks, notebook animation, and interactive `MapSequence` exploration are optional only; test a saved static figure instead.
- Large reprojection, full-disk mosaics, exact/adaptive algorithms on production arrays, and codec-heavy JP2 work require a separately budgeted runtime check.

# CLI and Automation Troubleshooting

## Command not found

Symptom: `data_profiling: command not found` or `pandas_profiling: command not found`.

Recovery:
1. Confirm the package is installed in the intended environment:
   `python -m pip show fg-data-profiling`.
2. From the root skill directory, run `python scripts/check_environment.py --json`
   or inspect `PATH` for the environment's script directory.
3. If automation runs in a scheduler/container, install the package in that
   runtime image rather than only in your interactive shell.

## Parser rejects `--minimal` with `--config_file`

The CLI passes both values into `ProfileReport`, where `minimal` and
`config_file` are mutually exclusive. Remove `--minimal` and encode minimal
settings in the YAML file, or remove `--config_file` and use the built-in
minimal preset.

## Browser opens during automation

Use `--silent`. Without it, `to_file(..., silent=False)` may open a browser or a
notebook/Colab download path after writing the report.

## Unsupported or misread file extension

- `.tar` is not supported by the package reader; extract the file or write a
  custom Python loader.
- Unknown extensions are assumed CSV-like and warn. If parsing is wrong, use
  pandas directly in a Python wrapper and pass a DataFrame to `ProfileReport`.
- Parquet, Excel, SAS, and some compressed files may need the corresponding
  pandas optional reader dependencies in the environment.

## Output path surprises

If `output_file` is omitted, the CLI writes next to the input using the input
stem and `.html`. In production jobs, pass an explicit output path so reports do
not land in unexpected data directories.

## Legacy command naming

`pandas_profiling` is a compatibility CLI name. Prefer `data_profiling` in new
scripts so the command matches the current import and package naming.

## Slow profiles in jobs

Start with `--minimal`, sample upstream, or use a YAML config generated by the
configuration/output sub-skill to disable expensive sections. Do not compensate
by raising `--pool_size` on a memory-constrained worker before reducing the
workload.

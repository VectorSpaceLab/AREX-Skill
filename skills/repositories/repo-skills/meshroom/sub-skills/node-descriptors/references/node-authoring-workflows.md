# Node Authoring Workflows

## Python Node

1. Choose `desc.Node` and declare inputs/outputs.
2. Use output expressions rooted at `{nodeCacheFolder}` for files generated by the node.
3. Implement `process(self, node)` for one-shot work or `processChunk(self, chunk)` for chunked work.
4. Write logs through `chunk.logger`/`chunk.logManager` when chunk-aware.
5. Register the containing package through a plugin path and test the descriptor in a small graph.

## Command-Line Node

```python
from meshroom.core import desc

class ListFiles(desc.CommandLineNode):
    commandLine = "ls {inputValue} > {outputValue}"
    inputs = [desc.File(name="input", label="Input", description="", value="")]
    outputs = [desc.File(name="output", label="Output", description="", value="{nodeCacheFolder}/files.txt")]
```

The placeholder names come from the node's expanded variables; inspect generated command lines with the node-command-line formatting tests or a tiny fixture. Quote paths when overriding `buildCommandLine` manually. Do not use shell syntax as a substitute for a proper executable when the node must run cross-platform.

## Init/Input Nodes

Use `desc.InitNode, desc.InputNode` for values set by batch/UI inputs rather than computed. `initialize` receives two lists: direct inputs and recursively discovered inputs. Validate paths and raise a useful error instead of silently accepting a missing file.

## Output Nodes and Templates

Output nodes are retained when a template is initialized with outputs enabled. The CLI can target exposed output attributes; only attributes listed in `outputAttributes` are legal targeted settings. File attributes in the exposed list are treated as output folders.

## Dynamic and Compound Values

- For dynamic outputs, use `value=None` in the descriptor and assign a value during processing.
- For `ListAttribute`, work with child attributes (`node.files.value`, `node.files.at(index)`) rather than assuming raw strings everywhere.
- For `GroupAttribute`, access named children (`node.advanced.strict.value`).
- For `AnySet`, expect children to be added/removed and preserve ordering/edges when serializing.

## Scene Helper Nodes

The built-in general nodes demonstrate a useful composition:

- `MeshroomSceneParameter` formats `NODEINSTANCE.attr=value` or `NODETYPE:attr=value` override strings.
- `GenerateMeshroomScene` calls `meshroom_batch` with a template, input/parameter overrides, save path, and `--compute no` to generate a configured scene.
- `GetMeshroomSceneParams` extracts values from another `.mg` scene into JSON.
- `UnwrapMeshroomSceneParam` turns selected JSON entries back into a graph value.

Treat those helpers as graph nodes, not as a replacement for validating the source template and node names.

# DeepResearch / WebAgent / Agent Family Map

This reference distills the inspected repository evidence into a self-contained family map. Use it to route tasks without opening the original project documentation.

## Runnable code versus notes

Use these labels when handing off a plan:

- **Reroute to sibling skill:** Root DeepResearch inference and official benchmark mechanics have dedicated sibling sub-skills.
- **Partially runnable with prerequisites:** WebDancer, WebSailor, WebResummer, WebWeaver, WebWalker, WebWatcher, AgentFold, ParallelMuse, and NestBrowse contain code, but most require model weights, GPUs or OpenAI-compatible endpoints, search/visit credentials, and prepared data.
- **Data/reference available:** WebShaper provides a bundled sample dataset. WebWalker describes a public dataset and includes local code. WebSailor includes sample task data.
- **Paper/model note in this checkout:** WebSailor-V2, WebResearcher, WebLeaper, AgentFounder, and AgentScaler are mostly methodological documents in the inspected tree; do not promise an end-to-end local command from this sub-skill alone.

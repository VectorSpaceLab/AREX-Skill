# VGen data formats

Use this reference when validating prompt lists, dataset lists, or DreamVideo metric inputs.

## Prompt-only lists

Used by ModelScope T2V, TF-T2V text inference, VideoLCM text inference, and some HiGen/SR600 flows.

```text
A video of a duckling wearing a medieval soldier helmet and riding a skateboard.
Astronaut riding a horse.
# comments are skipped
```

Rules:

- One prompt per active line.
- Comment lines start with `#`.
- Blank lines should be removed unless a specific helper says they are allowed.
- Some HiGen and SR600 examples accept `caption|manual_seed`; do not assume every prompt-only entrypoint does.

## Path-plus-caption lists

Used by image-conditioned, video-conditioned, and training datasets.

```text
relative_file_or_image.jpg|||caption text
relative_video.mp4|||caption text
```

Rules:

- Use exactly one `|||` delimiter.
- Keep both fields non-empty.
- Paths are usually resolved relative to a configured `data_dir`, `data_dir_list`, or the current checkout root.
- The repo's image-to-video and DreamVideo custom flows both rely on this format.

## VideoComposer-style lists

Used by TF-T2V and VideoLCM conditioning configs that consume source video clips.

```text
10000.mp4|||A boat docked on the beach and the wind picked up
1066674790.mp4|||croissants with icing sugar on a wooden plate sprinkled with almonds slow motion
```

Rules:

- The left field is a video key relative to `data_dir`.
- Captions may append `|manual_seed` in specific vcomposer variants.
- Conditions like `depth`, `sketch`, and `local_image` are generated by the entrypoint or annotator path, not by the list file itself.

## DreamVideo metric prompts

Used by the DreamVideo metric helper.

```text
video_filename|||reference_img_folder|||text_prompt
```

Rules:

- The video filename must match a file in the generated-video directory.
- The reference image folder must contain `.jpg` images.
- The prompt file is paired with one generated video per row.

## InstructVideo reward lists

Training rows:

```text
relative_video_path|||caption text
```

Evaluation rows:

```text
video_or_placeholder.mp4|||caption text|||frame_count
```

The evaluation video field is used for output naming, not as an input video.

## Quick validation path

Use the bundled `scripts/inspect_list_file.py` helper with `--kind` set to `prompt`, `prompt-or-seed`, `path-caption`, or `metric`.

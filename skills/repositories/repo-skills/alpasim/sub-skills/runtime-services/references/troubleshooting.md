# Runtime troubleshooting

Use the smallest diagnostic first: inspect the resolved YAML with
`scripts/inspect_runtime_config.py`, then read the first causal runtime/service
log. Do not repeatedly retry a deterministic configuration error.

| Surface | Observable symptom | Likely cause | Recovery |
| --- | --- | --- | --- |
| Install/import | `No module named alpasim_runtime`, missing generated proto import, or CLI absent | Runtime package/workspace extras are not installed in the active environment, or generated stubs are stale | Use the project installation path owned by `simulation-wizard`/developer tools; run a safe package import and `python -m alpasim_runtime.simulate --help`. Do not claim service readiness from an import. |
| Optional backend | Renderer/model/physics import succeeds but container or RPC fails; CUDA, Warp, PyG, checkpoint, or image errors | Optional GPU/backend dependency or container asset is missing | Use CPU/mock runtime checks for event/config behavior. Route model, plugin, physics, and deployment dependency repair to the owning sibling route. Full video-model/CATK/NuRec coverage remains blocked until its server, assets, and backend are ready. |
| Config parse | Missing required config, `???`, unknown field, or `OmegaConf` conversion error | Unresolved Hydra config, wrong config file, or hand-edited generated YAML | Regenerate/resolve configs through `simulation-wizard`; run the bundled checker against the resolved user config; preserve the generated network/evaluation files as a matched set. |
| Timing | `out of sync with planning`, stale camera list, egopose timestamp mismatch, or video chunk alignment error | `control_timestep_us`, camera cadence, pose cadence, force-GT, or chunk sizes do not form the expected integer grid | Check every camera, use `pose_reporting_interval_us: 0` unless intermediate reports are intentional, and apply the equations in [configuration and timing](configuration-and-timing.md). Turn off zero-delay assertion only with an explicit asynchronous-policy reason. |
| Video config | `fps must be positive`, invalid forwarding mode, HD-map forwarding guard, or force-GT remainder error | Invalid `VideoModelConfig` or first/regular chunk duration mismatch | Fix the resolved renderer config; use a matching chunk preset; require `control_timestep_us == chunk_frames * floor(1e6/fps)` and a force-GT duration covering first plus one regular chunk. |
| Port/readiness | `UNAVAILABLE`, connection refused, version probe timeout, or daemon port accepts no RPC | Backing service not started, wrong generated address, network namespace mismatch, or cold model/cache startup | Compare the exact address in network config with service logs; wait for readiness; increase startup timeout only for known cold startup. For external services, verify reachability without rewriting generated addresses. |
| Version consistency | Startup aborts with mixed versions across addresses | Replicas of one service do not report the same version/API identity | Align service images/builds or narrow the pool; do not suppress the check because runtime logs one canonical version per service. |
| Scene validation | Unknown scene, scene unavailable, duplicate scene IDs, or artifact discovery returns none | Scene ID is absent from the configured provider, artifact path/cache is wrong, or duplicate metadata exists | Validate the scene catalog and artifact cache with the deployment/data owner. For daemon requests, use only scene IDs returned by runtime discovery. |
| Missing completion | Rollout directory/ASL exists but `_complete` is absent | Event handling, worker, service, or evaluation failed before successful teardown | Read runtime and service logs around the first exception; keep the partial output for diagnosis. A retry may clean a session-specific failed directory only under runtime-controlled safe paths. |
| Worker failure | `worker crashed`, cancelled inline task, no result, or dispatch loop failure | Child import/process error, service RPC exception, orphaned worker, or resource exhaustion | Re-run one worker and one rollout; inspect traceback and service capacity. Increase workers/concurrency only after the inline case succeeds. |
| Empty/invalid endpoint pool | Service marked non-skipped but has no address; no dispatch capacity | Generated network config missing endpoint or skip flags disagree with deployment | Regenerate matching user/network configs. A skipped service is intentional only when its simulation mode permits it. |
| Physics skip mismatch | `Physics update mode requires the physics service` or inverse assertion | Physics endpoint skip flag and `physics_update_mode` disagree | Set mode `NONE` when physics is skipped, or run the physics service for `EGO_ONLY`/`ALL_ACTORS`. |
| Replay mismatch | `Request not found`, `Response without pending request`, unmatched requests, or `INVALID_ARGUMENT` diff | Runtime request chronology/shape changed, fixture uses another scene/config, or timestamps/camera grouping differ | Check first unconsumed exchange, dynamic-field normalization, service versions, and multi-pose egomotion grouping. Replay is fixture-bound and principally single-instance. |
| Replay session | `Session not found` on close | Session open was not matched or teardown ordering changed | Confirm start/close exchange order and UUID handling; do not invent a session in the fixture. |
| Calibration/assets | Missing `calibration_estimate.parquet`, first frames, HD-map, or unsupported FTheta model | USDZ is incomplete, wrong scene artifact, or camera selection is not in recorded calibration | Use a compatible artifact and recorded camera preset. Resolution-only override is safe for video-model bootstrap; pose/intrinsics override is not. |
| Renderer cache | Scene-affine startup reports unimplemented introspection; jobs cold-load repeatedly; stale output after config change | Renderer lacks cache RPC, cache evicted, or force-GT signature no longer matches render settings | Disable scene-affine dispatch when introspection is unsupported. For force-GT cache, use a new `extra_key`/cache location after renderer/camera changes. Distinguish Python artifact cache from renderer backend cache. |
| Daemon request | Unknown scene, mismatched session UUID count, invalid driver concurrency, or nonzero video-model offset rejected | Request violates runtime validation | Call runtime discovery first; make `len(session_uuids) == nr_rollouts`, use known scenes, set positive `n_concurrent_per_driver`, and omit video-model start offsets. |
| Shutdown | Client hangs after runtime finishes or backing containers remain | One-shot runtime ended but Compose is waiting on long-lived services, or graceful shutdown was not requested | Use the deployment route's runtime completion/exit-code handling; daemon clients request shutdown and wait for the RPC/server stop. Do not kill services before collecting logs. |

Stop and ask for operator input when recovery needs credentials, external
network access, destructive cache deletion, container/image builds, scheduler
submission, or large model/scene downloads. Those are not safe bundled runtime
operations.

# Plotting and benchmarking troubleshooting

Use this matrix when RL Zoo plotting or benchmark-result commands fail. Keep fixes local and explicit; do not switch to live Hub downloads or long training unless the caller approved that workflow and the task is routed to the appropriate sibling sub-skill.

| Symptom | Likely cause | Fix |
| --- | --- | --- |
| `ModuleNotFoundError: seaborn`, `pytablewriter`, `scipy`, or plotting import failure | Plotting extras are not installed. The `rl_zoo3` console router imports plotting modules even for some non-plot commands. | Install the package with plotting extras, for example `pip install "rl_zoo3[plots]"`, or install the missing plotting libraries. For non-plot train/eval tasks, prefer module commands such as `python -m rl_zoo3.train` or route to the relevant sub-skill. |
| Import failure mentioning `arch`, `rliable`, or pandas API compatibility | The rliable/arch stack may not yet support pandas 3.x. This compatibility issue was observed during package inspection. | Constrain pandas below 3 while keeping a modern 2.x release, e.g. `pip install "pandas>=2.2,<3"`. Then rerun the plotting help/import check. |
| `plot_train` opens no window or crashes with display/GUI errors | Headless shell, CI runner, SSH session, or missing GUI backend. | Use `MPLBACKEND=Agg` before plotting commands. For `all_plots`, also pass `--no-display`. `plot_train` has no save flag; for saved figures use evaluation files with `all_plots` + `plot_from_file`. |
| `plot_from_file` still tries to show a figure after `--output` | The command saves the final sensitivity plot but still calls `plt.show()`. | Run with `MPLBACKEND=Agg` in headless contexts. Verify the output file after command completion. |
| `all_plots` prints `Eval not found for ...` | Matching run folders do not contain `evaluations.npz`; training may have been run without evaluation callbacks or with a different log folder. | If Monitor CSV files exist, use `plot_train`. To create future evaluation files, route to [`../../training-cli/SKILL.md`](../../training-cli/SKILL.md) and train with an evaluation frequency. To inspect model/log layout, route to [`../../evaluation-and-artifacts/SKILL.md`](../../evaluation-and-artifacts/SKILL.md). |
| `all_plots` produces `0.0 +/- 0.0` or omits a run | Evaluation files are incomplete, shorter than the selected horizon, missing the selected `--key`, or filtered by `--min-timesteps` / `--max-timesteps`. | Check that every selected `evaluations.npz` has `timesteps` and the selected key with the same first dimension. Lower `--min-timesteps`, raise/lower `--max-timesteps` intentionally, or compare only runs with a common evaluation horizon. |
| `KeyError` for a selected evaluation key | `--key` is not present in all `evaluations.npz` files. | Use the default `--key results` for rewards, or verify that all files contain the alternate key such as a success-rate array before using it. |
| `plot_train` shows an empty legend or no curve | The rolling window is larger than the number of Monitor episodes, so the timeseries is skipped. | Reduce `--episode-window` (for example from 100 to 10 or 20) or gather more episodes before plotting. |
| `plot_train --y-axis success` reports no data | The Monitor CSV lacks an `is_success` column because the environment did not report success info. | Use `--y-axis reward` or `--y-axis length`, or train/evaluate with an environment that emits success information. |
| All selected env folders are ignored | `--env` is a substring matched against folder names. The key may not match the actual run directory. | Inspect the local log folder names and use a substring that appears in them, such as `Half` for `HalfCheetah...` folders or the full environment id when that is how runs are named. |
| `all_plots -o output.pkl` writes `output.pkl.pkl` | `all_plots` appends `.pkl` to the output string. | Pass an output stem, e.g. `--output ./plots/offpolicy`, not `--output ./plots/offpolicy.pkl`. |
| Label mismatch or strict zip error in `plot_from_file` | `--labels` count does not match the number of method keys retained after filtering. | First run without `--labels` and read the printed `keys: [...]` line. Then provide exactly one label per retained key or filter with `--keep-keys`. |
| rliable import error when using `--rliable` | `rliable` is optional and not installed, or its dependencies are incompatible. | Install/repair plotting extras and pandas compatibility. If unavailable, omit `--rliable`, `--versus`, and `--iqm` and use standard plots/tables. |
| rliable warns that an env is not found for normalizing scores | The built-in `env_key_to_env_id` mapping is limited to a few environment keys, and reference min/max scores are limited too. | Treat the output as raw-score comparison, not normalized-score evidence. Prefer supported keys (`Half`, `Ant`, `Hopper`, `Walker`, `LunarLanderContinuous`, `BipedalWalker`) only when they match the intended environment version. |
| `--iqm` rliable sample-efficiency plot fails or is missing data | Older or hand-built result pickles may lack `mean_per_eval`, or retained algorithms have incompatible evaluation dimensions. | Regenerate the `.pkl` with `all_plots` from complete `evaluations.npz` files, or omit `--iqm` and keep aggregate/final rliable plots only. |
| Benchmark command attempts network access or lists many remote models | `--no-hub` was omitted, so the benchmark module augments local models with the Hugging Face catalog. | Add `--no-hub` for offline/local checks. If live Hub use is desired, route to [`../../integrations-hub-tracking/SKILL.md`](../../integrations-hub-tracking/SKILL.md). |
| Benchmark tries to download a model even with local paths | The selected local trained-agent folder is incomplete, especially missing saved hyperparameters/config needed after evaluation. | Inspect the local artifact layout through [`../../evaluation-and-artifacts/SKILL.md`](../../evaluation-and-artifacts/SKILL.md). For strict offline mode, use complete local artifacts before running benchmark. |
| Benchmark fails with missing `enjoy.py` | The benchmark module delegates evaluation to a local command shim; package-only workspaces may not provide it. | Use the benchmark module only in a workspace that intentionally has a compatible shim. Otherwise build explicit `python -m rl_zoo3.enjoy` evaluation commands through [`../../evaluation-and-artifacts/SKILL.md`](../../evaluation-and-artifacts/SKILL.md). |
| Benchmark overwrites or modifies an unexpected `benchmark.md` | `--test-mode` was omitted; full benchmark copies the generated table to `benchmark.md` in the current working directory. | Use `--test-mode` for smoke tests. For full refreshes, set the current directory intentionally and keep a separate `--benchmark-dir`. |
| Benchmark does nothing or writes an empty table | `--log-dir` has no discoverable trained-agent folders with `args.yml`, or all selected envs are skipped. | Verify local model layout and optional environment dependencies. Use `--no-hub` only when local fixtures exist; otherwise route Hub download planning to the integrations sub-skill. |

## Fast preflight checklist

1. Run the bundled command builder with `--check-inputs` before any plot/benchmark command.
2. For plotting in headless mode, ensure `MPLBACKEND=Agg` is present; for `all_plots`, ensure `--no-display` is present.
3. For `all_plots`, verify `evaluations.npz` files contain `timesteps` and the selected key.
4. For `plot_from_file --rliable`, verify method labels, environment normalization coverage, and pandas/rliable compatibility.
5. For benchmarks, keep `--test-mode --no-hub` unless the caller explicitly accepts full-table and network side effects.

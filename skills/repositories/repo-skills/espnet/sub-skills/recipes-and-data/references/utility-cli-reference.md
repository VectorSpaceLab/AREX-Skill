# ESPnet2 Utility CLI Reference

These utilities are useful without launching a full recipe.

## `tokenize_text`

```bash
python -m espnet2.bin.tokenize_text --input text --output tokenized --field 2- --token_type char
python -m espnet2.bin.tokenize_text --input text --output tokenized --field 2- --token_type bpe --bpemodel bpe.model
```

Important options include `--token_type {char,bpe,word,phn}`, `--bpemodel`, `--g2p`, `--write_vocabulary`, `--vocabulary_size`, and `--add_symbol`. G2P and BPE choices can require optional packages or model files.

## `split_scps`

```bash
python -m espnet2.bin.split_scps --scps wav.scp text --names wav text --num_splits 4 --output_dir split4
```

Use this to create aligned split files for parallel jobs. Keys across input scp-like files must be compatible.

## `aggregate_stats_dirs`

Use repeated `--input_dir` arguments and one `--output_dir` to merge stats directories generated by distributed/parallel stats collection. Add `--skip_sum_stats` when sum-stat aggregation is inappropriate.

## `pack`

`python -m espnet2.bin.pack <task>` packages trained models and their configs for distribution. Supported tasks include `asr`, `st`, `tts`, `enh`, `diar`, `svs`, `s2t`, `s2st`, `spk`, `lid`, `codec`, and `cls`. Each task uses task-specific config/model option names such as `--asr_train_config`/`--asr_model_file`, `--st_train_config`/`--st_model_file`, or generic `--train_config`/`--model_file`.

Packaging and upload steps can expose credentials, caches, or model artifacts. Ask before packing for publication or uploading.
